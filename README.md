# ตำนานยุทธภพชางหลาน (Canglan Jianghu Online)

เอกสารออกแบบเกม (GDD) สำหรับเกม **text-based MMORPG กำลังภายในจีน** แนว JY Online
(มังกรหยกออนไลน์) ที่มีโลก/เนื้อเรื่อง/วิชา/สำนักเป็น **ต้นฉบับทั้งหมด** สำหรับแพลตฟอร์มเว็บ

## แนวคิดแกนกลาง
- **ไม่มีเลเวลตัวละคร** — ตัวละครเก่งขึ้นจากการ **ฝึกวิชาให้ระดับดาวสูงขึ้น**
- **ประสบการณ์ต่อสู้จริง (Combat EXP) = สกุลเงินฝึกวิชา** — สะสมจากการรบแล้วนำไปกดฝึก
- ใช้ **ค่าความเข้าใจ (COM)** เป็นเพดานดาวที่ฝึกได้ และ **ชื่อเสียง (Fame)** เป็นเพดานสะสม EXP
- การต่อสู้ **Real-time บนกริด + Action Gauge (ATB)** เคลื่อนที่จัดตำแหน่งแล้วปล่อย Radial AoE
  ล้างฝูงศัตรู ตัดสินด้วยการจัดบิลด์/วิชา/ตำแหน่ง (รายละเอียด: docs/11)
