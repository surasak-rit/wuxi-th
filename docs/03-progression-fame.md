# 03 — ความก้าวหน้า, ประสบการณ์ต่อสู้ & ชื่อเสียง (Progression / Combat EXP / Fame)

> หลักการ: **ไม่มีเลเวลตัวละคร** — Combat EXP คือ "สกุลเงินฝึกวิชา" (training currency)
> เพดาน EXP ผูกกับชื่อเสียง บังคับให้ผู้เล่นออกไปทำคอนเทนต์หลากหลาย (pacing แทนเลเวล)

---

## 1. ภาพรวมเส้นทางการเติบโต
```
ต่อสู้ ──► Combat EXP (มีเพดานสะสมตามชื่อเสียง)
                │
                ├──► ฝึกวิชา (เพิ่มระดับ Lv)    ← gate ด้วย COM
                ├──► อัปค่าพื้นฐาน (+1 ต่อครั้ง) ← ต้นทุนพุ่งตามค่า
                └──► (สะสมไว้ใช้ภายหลัง)
ชื่อเสียง (Fame) ──► ปลดเพดาน EXP / ปลดวิชาใหม่ / สิทธิ์สังคม (ตั้งสำนัก ฯลฯ)
ความเข้าใจ (COM) ──► เพดานระดับวิชาที่ฝึกได้ (level_cap)
```

## 2. Combat EXP — แหล่งที่มา & สูตร
```python
PI = sum(attributes) + sum(skill_level) + gear_score + fame_level*5   # ดัชนีพลังรวม

diff_factor  = clamp(enemy_PI / player_PI, 0.10, 2.00)
weak_penalty = 0.2 if (enemy_PI/player_PI) < 0.5 else 1.0
party_factor = 1.0 + 0.10*(party_size-1)            # 2 คน +10% ... 5 คน +40%
rested_factor= 1.5 if has_rested else 1.0           # สะสมตอนออฟไลน์/นั่งสมาธิในเมือง

combat_exp = round(enemy_base_exp * diff_factor * weak_penalty * party_factor * rested_factor)
```
**แหล่ง EXP:**
| แหล่ง | base_exp (อ้างอิง) | หมายเหตุ |
|---|---|---|
| มอนสเตอร์ทั่วไป | 30–120 | ตาม PI มอน |
| มอนสเตอร์ชั้นยอด (elite) | 250–600 | spawn จำกัด |
| บอสภูมิภาค | 2,000–6,000 | cooldown รายวัน/สัปดาห์ |
| บอสโลก | 10,000+ | แชร์ทั้งเซิร์ฟ ตาม contribution |
| PvP (ดวลจัดอันดับ) | 100–500 | กันฟาร์มซ้ำคู่เดิม (diminishing) |
| ภารกิจ | 200–3,000 | จ่ายตรง ไม่ติด weak_penalty |

> **กันปั๊มไม่สมดุล:** ตีมอนที่ PI < ครึ่งของเรา → EXP เหลือ 20%; ฟาร์ม PvP คู่เดิมซ้ำ →
> EXP ลดทบต่อครั้ง (รีเซ็ตรายวัน); rested จูงใจผู้เล่นเวลาน้อยให้ได้ EXP เข้มข้นช่วงสั้น

## 3. เพดานแต้มผูกชื่อเสียง (Fame & EXP Cap)
```
exp_cap = 500 + fame_level * 1500
```
| Lv | ชื่อระดับ | เพดาน EXP | ปลดล็อกโดย | สิทธิ์ที่ได้ |
|---|---|---|---|---|
| 1 | ผู้พเนจร | 2,000 | เริ่มเกม | วิชาพื้นฐานสำนัก |
| 2 | จอมยุทธ์หน้าใหม่ | 3,500 | ภารกิจชื่อเสียง 1 (ฆ่ามอน X, ช่วย NPC) | บรรทัดสคริปต์รบ +1 |
| 3 | นักดาบเลื่องชื่อ | 5,000 | ภารกิจ 2 + ฆ่าบอสภูมิภาค | วิชาขั้นสูง, เข้าดันเจี้ยน |
| 4 | ผู้กล้ายุทธภพ | 6,500 | ภารกิจ 3 + เข้าร่วมสำนักผู้เล่น | **ตั้งสำนักได้**, วิชาสุดยอด (req4) |
| 5 | ปรมาจารย์ | 8,000 | ภารกิจองก์ปลาย + อันดับ PvP | สคริปต์รบเต็ม 10, ฉายาพิเศษ |

**เมื่อ EXP เต็มเพดาน:**
- เก็บเพิ่มไม่ได้ (มอน drop EXP = 0) → แจ้งเตือน "ลมปราณเปี่ยมล้น ต้องสั่งสมชื่อเสียงเพิ่ม"
- ทางแก้: ใช้ EXP (ฝึกวิชา/อัปค่า) ลงให้ต่ำกว่าเพดาน หรือทำภารกิจปลดเพดานถัดไป
> **เหตุผล:** สร้าง "จังหวะหายใจ" ของเกม — สู้สะสม → หยุดมาฝึก/ทำเควส → ออกไปสู้ต่อ
> ป้องกัน no-life ฟาร์มจุดเดียวข้ามวัน และผูกความก้าวหน้ากับการสำรวจคอนเทนต์ทั้งเกม

## 4. การใช้ EXP — ตารางต้นทุนรวม
**4.1 ฝึกวิชา (ระดับ 1–100 — ดู docs/02)**
```
train_cost(L) = round(2 * L**1.7)   # L = ระดับปัจจุบัน → L+1  (L = 1..99)
```
| Lv→ | 1→2 | 10→11 | 20→21 | 30→31 | 40→41 | 50→51 | 60→61 | 70→71 | 80→81 | 90→91 | 99→100 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| EXP/ระดับ | 2 | 100 | 326 | 649 | 1,058 | 1,546 | 2,108 | 2,740 | 3,438 | 4,200 | 4,939 |
| สะสมถึง Lv นั้น | 2 | 423 | 2,579 | 7,539 | 16,212 | 29,416 | 47,909 | 72,407 | 103,591 | 142,110 | 183,567 |

> ฝึกวิชา 1 ท่าจาก Lv1→100 = **183,567 EXP** (ต้องมี COM 80) — ระดับต้นไต่เร็ว (รู้สึกคืบหน้า)
> ระดับปลายแพงขึ้นชัด; สมดุลกับเพดาน EXP 8,000 + ฟาร์มปลายเกม ให้วิชาสุดยอด 1 ท่าใช้เวลา
> "หลายสัปดาห์ถึงเป็นเดือน" — เป็นเป้าหมาย endgame ระยะยาว

**4.2 อัปค่าพื้นฐาน**


> เพื่อให้ค่าพื้นฐานโตช้ากว่าวิชา ทำให้สเปกตัวละครต่างกันด้วยการเลือก ไม่ใช่ทุกคนแม็กซ์หมด

## 5. กลไก Rested / EXP สะสมออฟไลน์
```python
# สะสมขณะออฟไลน์ หรือ นั่งสมาธิในเมืองปลอดภัย
rested_pool += rest_rate * time_offline      # เพดาน rested = 1 วันของการฟาร์ม
```

## 6. ดัชนีพลังรวม (Power Index, PI) — ใช้แทนเลเวลทั่วทั้งเกม
ใช้ใน: คำนวณ EXP, จับคู่ PvP/ลีก, จัดระดับมอน/บอส, แสดง "ความแกร่ง" ของผู้เล่น
```python
PI = sum(attributes)                 # สูงสุด 400 (4 ค่า x 100)
   + sum(skill_level)               # active4+passive2 เต็ม Lv100 = 600
   + gear_score                      # อุปกรณ์ (ดู docs/05)
   + fame_level * 5                  # 5..25
# ช่วง PI โดยประมาณ: เริ่มเกม ~60 / กลาง ~500 / ปลาย ~1,200 / สุด(เทพ) ~2,000+
```

## 7. เส้นโค้งเวลาการเล่น (Pacing Target) — ออกแบบเพื่อ retention
| ระยะ | เวลาเล่นสะสม (เป้า) | สถานะตัวละคร |
|---|---|---|
| สัปดาห์ 1 | ~6 ชม. | ชื่อเสียง 2, วิชาหลัก 2 ท่า ~Lv40, จับ core loop ได้ |
| เดือน 1 | ~30 ชม. | ชื่อเสียง 3, วิชาขั้นสูง Lv60–70, เริ่มลงบอส/ดันเจี้ยน |
| เดือน 3 | ~100 ชม. | ชื่อเสียง 4, วิชาสุดยอด 1 ท่า, เข้าสงครามสำนัก |
| เดือน 6+ | endgame | ไล่ Lv100 หลายท่า, อัปค่าพื้นฐานสายลึก, แข่งอันดับ/ดินแดน |

> **เหตุผล:** หลายเป้าหมายซ้อนกัน (วิชา/ค่าพื้นฐาน/ชื่อเสียง/ดินแดน) ที่ "ไม่มีวันแม็กซ์ครบ
> ง่ายๆ" คือแกน retention — ผู้เล่นมีอะไรให้ไล่เสมอ แต่รู้สึกคืบหน้าทุกเซสชัน
