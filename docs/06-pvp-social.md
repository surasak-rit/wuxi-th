> จัดอันดับ, ระบบสังคมสไตล์ JY (อาจารย์-ศิษย์, สหาย, คู่บุญ)

## 1. การดวล (Duel)
- **ดวลยินยอม:** ท้าในเมือง ไม่เสียของ/ไม่ขึ้น karma; ใช้ฝึกฝน + จัดอันดับดวล
- **ดวลจัดอันดับ (Ranked):** จับคู่ตามช่วง PI/ลีก, ได้คะแนนอันดับ + EXP เล็กน้อย
- ใช้ "ค่าพลัง normalize" ในโหมด ranked บางส่วน (ลดช่องว่าง gear) ให้ **การจัดวิชา/แผนรบ**
  เป็นตัวตัดสิน ไม่ใช่ฟาร์มล้วน

## 2. ระบบ PK & ค่าสังหาร (Karma / 正邪)
```python
# ฆ่าผู้เล่นในแผนที่เปิด
if target.is_innocent:           # ไม่ได้ตอบโต้/ค่า karma สะอาด
    attacker.karma += 100
    if target.PI < attacker.PI*0.6:    # รังแกผู้อ่อนแอ
        attacker.karma += 100
        attacker.fame_negative += 1
karma -= decay_per_hour          # ลดเองตามเวลา
```
| ช่วง karma | สถานะ | ผลกระทบ |
|---|---|---|
| 0 | สะอาด (ขาว) | ปกติ |
| 1–199 | มัวหมอง (เทา) | NPC บางเมืองตั้งแง่ |
| 200–499 | นักฆ่า (แดง) | ยามเมืองโจมตี, ราคาซื้อ NPC แพงขึ้น |
| 500+ | มารร้าย (แดงเข้ม) | ตายแล้วเสี่ยง drop ไอเทม/ระดับวิชาตก, ค่าหัวประกาศจับ |
- **ระบบค่าหัว (Bounty):** ผู้เล่นตั้งค่าหัวคนที่ฆ่าตน → ผู้ล่าค่าหัวได้รางวัลเมื่อสังหารเป้า
- **ไถ่บาป:** ทำภารกิจ/นั่งสมาธิสำนึกผิด ลด karma
> **เหตุผล:** เปิดให้ PK มีเสรีภาพ (สมจริงแบบยุทธภพ) แต่ลงโทษการรังแกผู้เล่นใหม่หนัก —
> สมดุลระหว่างความตื่นเต้นโลกเปิดกับการปกป้องผู้เล่นหน้าใหม่ (retention)

## 3. ปาร์ตี้ (Party)
- 2–5 คน; แชร์ EXP ด้วย party_factor (+10%/คน), แชร์ drop ตามกติกา (รอบ/สุ่ม/contribution)
- ต้องการความหลากหลายบทบาท (tank/heal/dps) เพื่อลงบอส/ดันเจี้ยนยาก
- บัฟปาร์ตี้ตามองค์ประกอบสำนัก (เช่น มี healer วารีบูรพา → ทั้งทีม +regen นอกรบ)

## 4. สำนักผู้เล่น (Player Sect / Guild)
- ตั้งได้เมื่อชื่อเสียง ≥ 4 + เสียค่าก่อตั้ง (sink)
- โครงสร้าง: เจ้าสำนัก → รองเจ้าสำนัก → ผู้อาวุโส → ศิษย์
- **คลังสำนัก** (ฝาก/เบิกของร่วม, log การใช้), **ค่าสมาชิกรายสัปดาห์/บริจาค**
- **เทคโนโลยีสำนัก (Sect Tech):** ลงทุนเงิน/ทรัพยากรปลดบัฟส่วนรวม
  (เช่น −5% ต้นทุนฝึกวิชาสมาชิก, +rested rate, +HP ในสงคราม)
- **ที่ตั้งสำนัก:** เช่าพื้นที่ (sink รายสัปดาห์) ปลดสิ่งอำนวยความสะดวก (ลานฝึก/ร้านค้า/ลานสมาธิ)

## 5. สงครามแย่งชิงดินแดน (Sect War / Territory)
- **ศึกชิงเมือง:** เปิดรายสัปดาห์ในช่วงเวลากำหนด สำนักประกาศโจมตีเมืองเป้าหมาย
- รูปแบบ: ยึดจุดยุทธศาสตร์ (ป้อม/ธง) ภายในเวลา; วัดด้วยคะแนนยึดครอง + สังหาร
- จับคู่ด้วย **PI รวมสำนัก** + ระบบลีกดินแดน เพื่อกันสำนักยักษ์ทุบสำนักเล็กฝ่ายเดียว
- **ผลตอบแทนผู้ครองเมือง:**
  - เก็บภาษีตลาดเมืองนั้น (รายได้สำนัก → sink/แจกสมาชิก)
  - บัฟภูมิภาคแก่สมาชิก (เช่น +EXP/+drop ในเขตเมือง)
  - ชื่อเสียงสำนัก + สิทธิ์ NPC พิเศษ
- กลไกป้องกันผูกขาด: ภาษีถูก decay, ผู้ครองนานถูกตั้ง "เป้าใหญ่" (ผู้ท้าได้บัฟ), หมุนเวียนเมืองเปิดศึก

## 6. ระบบจัดอันดับ (Leaderboards)
| อันดับ | เกณฑ์ | รางวัลรายสัปดาห์ |
|---|---|---|
| จอมยุทธ์เดี่ยว | คะแนนดวล ranked | ของตกแต่ง/ฉายา/ไอเทมฝึก |
| ดัชนีพลัง (PI) | PI สูงสุด | ฉายา |
| ปรมาจารย์วิชา | ผลรวมระดับวิชา | ตำราหายาก (bind) |
| สำนักครองแผ่นดิน | จำนวนเมือง/คะแนนสงคราม | งบสำนัก/บัฟ |
> รางวัลเน้น **prestige + ของฝึก** ไม่ใช่พลังดิบล้วน → กัน "rich get richer" รักษาสมดุล

## 7. ระบบสังคมสไตล์ JY
- **อาจารย์–ศิษย์ (师徒):** ผู้เล่นชื่อเสียงสูงรับศิษย์; ศิษย์โตให้รางวัลทั้งคู่ (อาจารย์ได้ของ/ฉายา,
  ศิษย์ได้บัฟเรียนรู้ +prof). จูงใจผู้เล่นเก่าช่วยผู้เล่นใหม่ → retention/ชุมชน
- **ศิษย์ชั่วชีวิต (入室弟子):** ขั้นลึกสุดของการเป็นศิษย์สำนัก — ผูกกับสำนักเดียวตลอดชีพ
  (ออกได้แต่มีโทษหนัก) ปลดเควสรับ **วิชาลับ 3 ท่า (โจมตี/内功/ตัวเบา)** + สิทธิ์พิเศษ
  ดูกลไกเต็มใน **docs/02 §10**
- **สหาย (友):** เพื่อน, ระบบแชท, ตามไปช่วยรบ
- **คู่บุญ/สาบาน (结拜·姻缘):** จับคู่/ผูกสาบาน ปลดบัฟร่วมเมื่ออยู่ทีมเดียวกัน + เควสคู่
- **ฉายา (称号):** ได้จากความสำเร็จ แสดงเหนือชื่อ (prestige, ไม่ให้พลัง)

> **เหตุผล:** ระบบสังคมคือ "กาว" ของ MMORPG กำลังภายใน — ผูกผู้เล่นไว้กับชุมชนและสำนัก
> ทำให้เหตุผลในการกลับมาเล่นไม่ได้มีแค่ตัวเลขพลัง แต่รวมความสัมพันธ์และสถานะทางสังคม
