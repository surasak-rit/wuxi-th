# 02 — ระบบวิชา & การฝึกฝน (Skills & Cultivation) — สไตล์ JY Online

> หัวใจของเกม: ตัวละครเก่งขึ้นจาก **การฝึกวิชาให้ "ระดับ" สูงขึ้น (Lv 1–100)** ไม่ใช่เลเวลตัวละคร
> อ้างอิงสูตร: `train_cost(L)=round(2*L^1.7)`, `level_cap=min(100, floor(COM*1.25))`
> (สเกลหลักของวิชาคือ **ระดับ 1–100**; "ดาว" ใช้เป็นการแสดงผลแบบหยาบได้ที่ 1 ดาว = 10 ระดับ)

---

## 1. โครงสร้างวิชา (Skill Anatomy)
วิชาทุกท่ามีคุณสมบัติมาตรฐาน:
| ฟิลด์ | ความหมาย |
|---|---|
| `id`, `name` | รหัส/ชื่อวิชา (ต้นฉบับ) |
| `type` | active (โจมตี/ฟื้นฟู/คุม) หรือ passive (内功/กำลังภายใน) |
| `category` | สาย: กระบี่/ฝ่ามือ/พิษ/ลมปราณ/ตัวเบา |
| `grade` | ระดับวิชา: สามัญ / ดี / เลิศ / สุดยอด (คุมเพดานระดับ & พลังฐาน) |
| `base_mult` | ตัวคูณดาเมจฐาน |
| `mp_cost` | ลมปราณที่ใช้ต่อครั้ง |
| `max_level` | ระดับสูงสุด (สามัญ 70 / ดี 80 / เลิศ 90 / สุดยอด 100) |
| `effect` | เอฟเฟกต์เสริม (ดูด/สถานะ/บัฟ) |
| `prereq` | วิชา + ระดับที่ต้องมีก่อนเรียน |
| `req` | เงื่อนไขปลดล็อก: ค่าพื้นฐานขั้นต่ำ, COM, ชื่อเสียง, สังกัด |

## 2. ระดับวิชา (Skill Level 1–100) — ผลต่อพลัง
ทุกระดับที่เพิ่ม: `skill_mult += 0.01` (Lv100 → +1.0 เท่ากับเพดานพลังเดิม) และปลดผลพิเศษ
เป็นช่วง (ดูตารางใน GDD หลัก §4.1'C)
```python
def skill_power(skill, level):                                  # level 1..100
    mult      = skill.base_mult + level * 0.01
    mp_cost   = round(skill.mp_cost * (1 - min(level,70)*0.003)) # ระดับสูง = ประหยัดลมปราณ (สูงสุด -21%)
    proc      = skill.effect_chance + (0.05 if level>=40 else 0) + (0.05 if level>=80 else 0)
    return mult, mp_cost, proc
```
**ปลดผลพิเศษตามระดับ (มาตรฐานทุกท่า):**
- Lv 40: +5% โอกาสติดเอฟเฟกต์
- Lv 60: ออกท่าเร็วขึ้น (SPD เฉพาะตา +10%)
- Lv 80: +5% โอกาสติดเอฟเฟกต์ (รวม +10%) / ปลดเอฟเฟกต์รอง
- Lv 100 (เฉพาะ grade สุดยอด): ปลด **"ขั้นสุดยอด"** — เอฟเฟกต์พลิกเกมประจำท่า
> บางวิชายัง **เปลี่ยนรูปทรง AoE ตามระดับ** (shape morph) ดู docs/12 §3.1

## 3. การฝึก (Cultivation Mechanics)
มี 2 ทางเพิ่มระดับ — JY-style ผสาน:
1. **ฝึกด้วย Combat EXP (กดฝึกที่สำนัก/ที่พัก)** — จ่าย EXP ตาม train_cost ได้ระดับทันที
   (เงื่อนไข: COM พอ + จ่ายค่าครู/ทรัพยากรเสริมบางระดับ)
2. **สะสมความชำนาญจากการใช้จริง (Proficiency)** — ใช้วิชาในรบสะสม prof; เต็มแถบลดต้นทุน
   EXP ของระดับถัดไป 20%
```python
prof_gain_per_use = 1 * hit_quality          # โดน/คริติคอล/ติดสถานะ = มากขึ้น
prof_to_next(L)   = 20 + L*3                  # แถบความชำนาญต่อระดับ
# เต็มแถบ → ระดับถัดไปจ่าย EXP ลด 20% (จูงใจ "ใช้วิชาที่ฝึก" ไม่ใช่ซื้อระดับล้วน)
```
> **เหตุผล:** รวมจุดเด่นของ JY — ทั้ง "ทุ่ม EXP" (เร่งได้ถ้ามีทรัพยากร) และ "ใช้จนชำนาญ"
> (รางวัลผู้เล่นที่ใช้วิชานั้นจริง) ทำให้บิลด์ที่ "ใช้สม่ำเสมอ" คุ้มกว่าการสลับมั่ว

## 4. ค่าความเข้าใจ (Comprehension / 悟性) — ตัว gate การเติบโต
```
level_cap = min(100, floor(COM * 1.25))    # COM 80 → ฝึกได้สูงสุด Lv100
```
| COM | เพดานระดับที่ฝึกได้ | หมายเหตุ |
|---|---|---|
| 8 | 10 | ผู้เริ่มต้น |
| 32 | 40 | กลางเกม |
| 56 | 70 | ปลดวิชาสามัญเต็ม |
| 72 | 90 | |
| 80+ | 100 | ปลดขั้นสุดยอดได้ |

**ได้ COM จาก (จงใจหายาก):** ภารกิจสายเนื้อเรื่อง, เศษคัมภีร์เทียนจี๋, บอสโลก, ของเลื่องชื่อ,
"พบแจ้งในธรรม" (random event หายากตอนนั่งสมาธิ +1 COM)
> **เหตุผล:** COM เป็น soft cap ที่ทำให้ผู้เล่นใหม่ไล่ตามได้ (EXP หาได้เรื่อยๆ) แต่ผู้เล่น
> ทุ่มเทระยะยาวยังนำหน้าด้วยเพดานระดับที่สูงกว่า — คุม power gap ไม่ให้พุ่งเร็วเกิน

## 5. ข้อจำกัดติดตัว & การจัดบิลด์
- ติดพร้อมใช้: **active 4 + passive(内功) 2**
- เปลี่ยนชุดวิชานอกการต่อสู้ได้ (มี "ผังวิชา" บันทึกได้ 3 ชุด เพื่อสลับ PvE/PvP/บอส)
- วิชาที่ไม่ได้ติดยังคงระดับไว้ (ไม่รีเซ็ต) แต่ไม่สะสม prof

## 7. วิชากำลังภายใน (内功 / Passive) — แยกระบบจากวิชาโจมตี
- ติดได้ 2 ช่อง เป็นโครงสร้างพลังของบิลด์ (เพิ่ม MP/HP/ค่าพื้นฐาน/ต้านทาน)
- บาง 内功 ให้ % ทับค่าฐาน — คำนวณ **หลัง** ค่าจากอุปกรณ์ (multiplicative)
```python
final_HP = base_HP * (1 + sum(passive_hp_pct)) + flat_hp_bonus
final_MP = base_MP * (1 + sum(passive_mp_pct)) + flat_mp_bonus
```
- 内功 ข้ามสำนักเรียนได้ถ้าตรงเงื่อนไข (ผ่านตำรา drop) → เปิดทางบิลด์ลูกผสม

> **เหตุผล:** การแยก passive 内功 ทำให้ผู้เล่นวางแผน "แกนพลัง" (เน้นเลือด/ลมปราณ/ความเร็ว)
> ได้อิสระจากชุดท่าโจมตี เพิ่มความหลากหลายบิลด์โดยไม่พังสมดุลสำนัก

## 8. การลืม/รีเซ็ตวิชา
- รีเซ็ตระดับวิชาเพื่อคืน EXP บางส่วน (คืน 50%) — ผ่านไอเทม "เคล็ดสำนึกผิด" (หายาก/ซื้อด้วยเงินมาก = sink)
- ป้องกันการสลับบิลด์ฟรีบ่อยเกิน รักษาความหมายของการเลือกฝึก
