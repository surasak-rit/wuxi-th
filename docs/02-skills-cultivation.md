# 02 — ระบบวิชา & การฝึกฝน (Skills & Cultivation) — สไตล์ JY Online

> หัวใจของเกม: ตัวละครเก่งขึ้นจาก **การฝึกวิชาให้ "ระดับ" สูงขึ้น (Lv 1–100)** ไม่ใช่เลเวลตัวละคร
> อ้างอิงสูตร: `train_cost(L)=round(2*L^1.7)`, `level_cap=min(100, floor(COM*1.25))`
> (สเกลหลักของวิชาคือ **ระดับ 1–100**; "ดาว" ใช้เป็นการแสดงผลแบบหยาบได้ที่ 1 ดาว = 10 ระดับ)

---

## 1. โครงสร้างวิชา (Skill Anatomy)
วิชาทุกท่ามีคุณสมบัติมาตรฐาน:
| ฟิลด์ | ความหมาย |
|---|---|
| `id`, `name` | รหัส/ชื่อวิชา (ต้นฉบับ) |
| `type` | active (โจมตี/ฟื้นฟู/คุม) หรือ passive (内功/กำลังภายใน) |
| `category` | สาย: กระบี่/ฝ่ามือ/พิษ/ลมปราณ/ตัวเบา |
| `grade` | ระดับวิชา: สามัญ / ดี / เลิศ / สุดยอด (คุมเพดานระดับ & พลังฐาน) |
| `base_mult` | ตัวคูณดาเมจฐาน |
| `mp_cost` | ลมปราณที่ใช้ต่อครั้ง |
| `max_level` | ระดับสูงสุด (สามัญ 70 / ดี 80 / เลิศ 90 / สุดยอด 100) |
| `effect` | เอฟเฟกต์เสริม (ดูด/สถานะ/บัฟ) |
| `prereq` | วิชา + ระดับที่ต้องมีก่อนเรียน |
| `req` | เงื่อนไขปลดล็อก: ค่าพื้นฐานขั้นต่ำ, COM, ชื่อเสียง, สังกัด |

## 2. ระดับวิชา (Skill Level 1–100) — ผลต่อพลัง
ทุกระดับที่เพิ่ม: `skill_mult += 0.01` (Lv100 → +1.0 เท่ากับเพดานพลังเดิม) และปลดผลพิเศษ
เป็นช่วง (ดูตารางใน GDD หลัก §4.1'C)
```python
def skill_power(skill, level):                                  # level 1..100
    mult      = skill.base_mult + level * 0.01
    mp_cost   = round(skill.mp_cost * (1 - min(level,70)*0.003)) # ระดับสูง = ประหยัดลมปราณ (สูงสุด -21%)
    proc      = skill.effect_chance + (0.05 if level>=40 else 0) + (0.05 if level>=80 else 0)
    return mult, mp_cost, proc
```
**ปลดผลพิเศษตามระดับ (มาตรฐานทุกท่า):**
- Lv 40: +5% โอกาสติดเอฟเฟกต์
- Lv 60: ออกท่าเร็วขึ้น (SPD เฉพาะตา +10%)
- Lv 80: +5% โอกาสติดเอฟเฟกต์ (รวม +10%) / ปลดเอฟเฟกต์รอง
- Lv 100 (เฉพาะ grade สุดยอด): ปลด **"ขั้นสุดยอด"** — เอฟเฟกต์พลิกเกมประจำท่า
> บางวิชายัง **เปลี่ยนรูปทรง AoE ตามระดับ** (shape morph) ดู docs/12 §3.1

## 3. การฝึก (Cultivation Mechanics)
> สรุปย่อ — ระบบฝึกปรือเต็ม (สถานที่ฝึก/ฝึกใช้เวลา-ออฟไลน์/ทะลวงด่าน/ฝึกร่วม) ดู **docs/13**

มี 2 ทางเพิ่มระดับ — JY-style ผสาน:
1. **ฝึกด้วย Combat EXP (กดฝึกที่สำนัก/ที่พัก)** — จ่าย EXP ตาม train_cost ได้ระดับทันที
   (เงื่อนไข: COM พอ + จ่ายค่าครู/ทรัพยากรเสริมบางระดับ)
2. **สะสมความชำนาญจากการใช้จริง (Proficiency)** — ใช้วิชาในรบสะสม prof; เต็มแถบลดต้นทุน
   EXP ของระดับถัดไป 20%
```python
prof_gain_per_use = 1 * hit_quality          # โดน/คริติคอล/ติดสถานะ = มากขึ้น
prof_to_next(L)   = 20 + L*3                  # แถบความชำนาญต่อระดับ
# เต็มแถบ → ระดับถัดไปจ่าย EXP ลด 20% (จูงใจ "ใช้วิชาที่ฝึก" ไม่ใช่ซื้อระดับล้วน)
```
> **เหตุผล:** รวมจุดเด่นของ JY — ทั้ง "ทุ่ม EXP" (เร่งได้ถ้ามีทรัพยากร) และ "ใช้จนชำนาญ"
> (รางวัลผู้เล่นที่ใช้วิชานั้นจริง) ทำให้บิลด์ที่ "ใช้สม่ำเสมอ" คุ้มกว่าการสลับมั่ว

## 4. ค่าความเข้าใจ (Comprehension / 悟性) — ตัว gate การเติบโต
```
level_cap = min(100, floor(COM * 1.25))    # COM 80 → ฝึกได้สูงสุด Lv100
```
| COM | เพดานระดับที่ฝึกได้ | หมายเหตุ |
|---|---|---|
| 8 | 10 | ผู้เริ่มต้น |
| 32 | 40 | กลางเกม |
| 56 | 70 | ปลดวิชาสามัญเต็ม |
| 72 | 90 | |
| 80+ | 100 | ปลดขั้นสุดยอดได้ |

**ได้ COM จาก (จงใจหายาก):** ภารกิจสายเนื้อเรื่อง, เศษคัมภีร์เทียนจี๋, บอสโลก, ของเลื่องชื่อ,
"พบแจ้งในธรรม" (random event หายากตอนนั่งสมาธิ +1 COM)
> **เหตุผล:** COM เป็น soft cap ที่ทำให้ผู้เล่นใหม่ไล่ตามได้ (EXP หาได้เรื่อยๆ) แต่ผู้เล่น
> ทุ่มเทระยะยาวยังนำหน้าด้วยเพดานระดับที่สูงกว่า — คุม power gap ไม่ให้พุ่งเร็วเกิน

## 5. ข้อจำกัดติดตัว & การจัดบิลด์
- ติดพร้อมใช้: **active 4 + passive 2** (passive 2 ช่อง = แกนมาตรฐาน "1 内功 + 1 ตัวเบา")
  **+ ช่องวิชาพิเศษนอกสำนัก 1 ช่อง** (universal art — ปลดเมื่อได้วิชาแรก, ดู §11)
- เปลี่ยนชุดวิชานอกการต่อสู้ได้ (มี "ผังวิชา" บันทึกได้ 3 ชุด เพื่อสลับ PvE/PvP/บอส)
- วิชาที่ไม่ได้ติดยังคงระดับไว้ (ไม่รีเซ็ต) แต่ไม่สะสม prof

# 6. สายวิชาครบ 6 สำนัก (Full Skill Trees)

สัญลักษณ์: ⚔ กระบี่ ✋ ฝ่ามือ ☠ พิษ 🌊 ลมปราณ 🍃 ตัวเบา | (P)=passive 内功
(คอลัมน์ maxLv = ระดับสูงสุดตาม grade; prereq ระบุเป็นระดับ Lv)
> ✦ **วิชาสืบทอด** (active ตัวที่กลายเป็น "วิชาสุดยอด") เดินเส้นทางด่านพิเศษ — เพดานด่าน
> 30/70/100 + แปรร่างตอน Lv100 ดู **§9**: เขาเมฆขาว=กระบี่ฟ้าสะท้านปฐพี, วารีบูรพา=มหาสมุทร
> หนุนปราณ, หุบเขายาพิษ=วารีพิษกลืนพสุธา, กระบองเหล็ก=กระบองพสุธาสะเทือน, ลมวสันต์=ฟ้าแลบสิบทิศ,
> วิหารดารา=มหาเวทย์ดาราล้างพิภพ

> 🧱 **โครงวิชา 3 เสา (ทุกสำนักมีเหมือนกัน):** ทุกสำนักต้องมีครบทั้ง
> ① **วิชาโจมตี** (active) ② **วิชากำลังภายใน 内功** (passive 🌊) ③ **วิชาตัวเบา** (passive 🍃)
> โดยมีชื่อ/จุดเด่นเป็นเอกลักษณ์ของแต่ละสำนัก — ช่อง passive 2 ช่อง (§5) ตั้งใจให้ใส่
> "1 内功 + 1 ตัวเบา" เป็นแกนมาตรฐาน (จะสลับเป็น 2 内功 หรือ 2 ตัวเบา ก็ได้ถ้ามี)
> *ตัวเบา* ส่งผลต่อ SPD/EVA/ความเร็วเดินบนกริด (สำคัญในระบบ real-time docs/11)

## 7. วิชากำลังภายใน (内功 / Passive) — แยกระบบจากวิชาโจมตี
- ติดได้ 2 ช่อง เป็นโครงสร้างพลังของบิลด์ (เพิ่ม MP/HP/ค่าพื้นฐาน/ต้านทาน)
- บาง 内功 ให้ % ทับค่าฐาน — คำนวณ **หลัง** ค่าจากอุปกรณ์ (multiplicative)
```python
final_HP = base_HP * (1 + sum(passive_hp_pct)) + flat_hp_bonus
final_MP = base_MP * (1 + sum(passive_mp_pct)) + flat_mp_bonus
```
- 内功 ข้ามสำนักเรียนได้ถ้าตรงเงื่อนไข (ผ่านตำรา drop) → เปิดทางบิลด์ลูกผสม

> **เหตุผล:** การแยก passive 内功 ทำให้ผู้เล่นวางแผน "แกนพลัง" (เน้นเลือด/ลมปราณ/ความเร็ว)
> ได้อิสระจากชุดท่าโจมตี เพิ่มความหลากหลายบิลด์โดยไม่พังสมดุลสำนัก

## 9. เส้นทางวิชาสุดยอดประจำสำนัก (Sect Ultimate Skill Path)
แต่ละสำนักมี **"วิชาสืบทอด" (active 1 ท่า)** ที่เดินเส้นทางพิเศษ — ปลด/ฝึกเป็น **ด่านสลับ**
ระหว่าง *เควส → ฝึกเอง → อาจารย์สอน → ฝึกเอง → เควสแปรวิชา* กว่าจะกลายเป็น **"วิชาสุดยอด"**
ของสำนัก จุดประสงค์: ทำให้ท่าไม้ตายของสำนักเป็น **เป้าหมายระยะยาวที่ต้องใช้ทั้งฟาร์ม
สังคม(อาจารย์) และเนื้อเรื่อง(เควส)** ไม่ใช่แค่ทุ่ม EXP อย่างเดียว

### 9.1 ด่านความก้าวหน้า (Gated Stages)
| ด่าน | ช่วงระดับ | วิธีผ่าน | เงื่อนไข/หมายเหตุ |
|---|---|---|---|
| ① ปลดล็อก | — → Lv1 | **เควสสืบทอดวิชาสำนัก** | ชื่อเสียง ≥ 3 + สังกัดสำนัก; จบเควสได้วิชาที่ Lv1 |
| ② ฝึกปรือเอง | Lv1 → 30 | ฝึกเอง (จ่าย Combat EXP) | ตาม train_cost(L) + COM พอ; **ตันที่ Lv30** ฝึกเองต่อไม่ได้ |
| ③ อาจารย์สอน | Lv30 → 70 | **เรียนกับอาจารย์สำนัก (NPC)** | ต้องอยู่กับอาจารย์ + ค่าครู (เงิน=sink) + contribution สำนัก; ยังจ่าย EXP ต่อระดับ |
| ④ ฝึกปรือเอง | Lv70 → 100 | ฝึกเองต่อ ("แตกฉานเอง") | อาจารย์สอนได้ถึง 70 เท่านั้น — ที่เหลือฝึกเอง; ต้อง COM 80 ถึงแตะ Lv100 |
| ⑤ แปรวิชา | Lv100 | **เควสสุดยอดวิชา** | แลกวิชาเป็น **"สุดยอด<ชื่อเดิม>"** + เปลี่ยนรัศมีเป็น **แบบ 5 (พีระมิด)** |
| ⑥ อ่านคัมภีร์ | Lv100 → 200 | **อ่านคัมภีร์สุดยอด** (อ่านไม่จำกัด; แต่ **แลก/ขอ จำกัด/วัน**) | อ่านได้ EXP วิชา → ดันระดับ; ข้ามเพดาน COM (คัมภีร์ให้ความเข้าใจ) ดู §9.5 |

> **กลไกด่าน:** ระบบ "ล็อกเพดานชั่วคราว" ต่อท่า — ฝึก/จ่าย EXP เกินเพดานด่านปัจจุบันไม่ได้
> จนกว่าจะปลดด่านถัดไป (เควส/อาจารย์) เพดาน COM (`level_cap=⌊COM×1.25⌋`) ยังคุมทับอีกชั้น
```python
def can_train_to(skill, target_level, player):
    stage_cap = 30 if not skill.master_taught else (70 if not skill.self_mastered else 100)
    return target_level <= min(stage_cap, floor(player.COM*1.25), 100)
# master_taught = ผ่านด่าน③ (เรียนอาจารย์แล้ว) ; self_mastered = ผ่านด่าน④ปลด (เควส/เงื่อนไข Lv70)
```

### 9.2 การแปรวิชา (Transformation @ Lv100)
เมื่อวิชาสืบทอดถึง **Lv100** ปลด **"เควสสุดยอดวิชา"** (ทดสอบฝีมือ/เก็บวัตถุดิบหายาก/เศษคัมภีร์):
- วิชาถูก **แปลงเป็นเวอร์ชันสุดยอด**: `id` ใหม่, ชื่อ = **"สุดยอด" + ชื่อเดิม**
- **รัศมีโจมตีเปลี่ยนเป็น แบบ 5 (พีระมิด วางจุดได้)** — docs/12 §แบบ5 (core 5×5 + เงี่ยง, เลือกจุดลงใน cast_range)
- คงระดับ Lv100 + ปลดเอฟเฟกต์ "ขั้นสุดยอด" ประจำท่า (ตาราง §6) + ป้ายฉายา/ชื่อเสียงสำนัก
- เป็น **one-way** (ถาวร) — ไม่ต้องไล่ระดับใหม่ (ยังคง Lv100)
```jsonc
// ก่อนแปร: วิชาสืบทอด (เช่น เขาเมฆขาว)
{ "id":"cloud_heaven_quake", "name":"กระบี่ฟ้าสะท้านปฐพี", "grade":"supreme",
  "max_level":100, "shape":{"type":"cross","params":{"length":3}} }
// หลังเควสแปร @Lv100:
{ "id":"cloud_heaven_quake_ULT", "name":"สุดยอดกระบี่ฟ้าสะท้านปฐพี", "grade":"supreme",
  "level":100, "max_level":200,    // ปลดเพดานถึง 200 ผ่านการอ่านคัมภีร์ (§9.5)
  "shape":{"type":"pyramid","params":{"core":5,"spike":1,"cast_range":5}},
  "evolved_from":"cloud_heaven_quake" }
```

### 9.4 เหตุผลเชิงดีไซน์
- **ด่านสลับ 3 กิจกรรม** (ฟาร์ม EXP / เข้าหาอาจารย์-สังคม / เนื้อเรื่อง-เควส) บังคับให้ผู้เล่น
  สัมผัสคอนเทนต์หลากหลายกว่าจะได้ท่าไม้ตาย → retention + ผูกกับระบบสังคม(อาจารย์-ศิษย์ docs/06 §7)
- **"อาจารย์สอนได้ถึง 70 เท่านั้น"** สื่อธีมกำลังภายใน "ครูพาไปได้ถึงจุดหนึ่ง ที่เหลือต้อง
  แตกฉานด้วยตนเอง" และเป็น gate ที่ต้องใช้ COM สูง (ทรัพยากรหายาก)
- **แปรเป็นแบบ 5 (พีระมิด วางจุด)** ตอน Lv100 ให้ "รู้สึกถึงการก้าวข้ามขั้น" — ท่าเดิมกลาย
  เป็นพื้นที่กว้างเลือกจุดลงกลางฝูง = พลังและการเล่นเปลี่ยนชัดเจน (ดู docs/12)

### 9.5 อ่านคัมภีร์สุดยอด: Lv100 → 200 (Manual Reading)
หลังแปรเป็นวิชาสุดยอดแล้ว เปิดช่องทาง **อ่านคัมภีร์** เพื่อดันระดับต่อจาก Lv100 ถึง **Lv200**
(endgame ที่ลึกสุด — แยกจากการฝึกด้วย Combat EXP ปกติ):

- **การอ่านไม่จำกัด:** อ่านคัมภีร์ที่มีในมือกี่ครั้งก็ได้ ทุกครั้งที่อ่าน 1 เล่ม → ได้
  **skill-EXP** ไปสะสมดันระดับ (ใช้ train_cost(L) เดิม; แหล่ง EXP เปลี่ยนจากรบเป็นการอ่าน)
- **คอขวดอยู่ที่การ "แลก/ขอ" คัมภีร์สุดยอด** ซึ่งคุมด้วยกฎ 3 ข้อ:
  1. **จำกัดจำนวนแลก/ขอต่อวัน** (daily request cap) — ใช้ contribution สำนัก/โทเคนปลายเกม
  2. **ถือได้ครั้งละ 1 เล่ม** — ถ้ามี "คัมภีร์สุดยอด" อยู่ในกระเป๋าแล้ว **แลก/ขอใหม่ไม่ได้**
     (ต้องอ่านให้หมดก่อนจึงขอเล่มถัดไปได้)
  3. **ผูกติดตัวเมื่อได้รับ (character-bound):** **ฝากคลัง/ย้ายออกจากกระเป๋า/เทรด/ขายไม่ได้**
- **ข้ามเพดาน COM:** ช่วง 100→200 ไม่ติด `level_cap` ของ COM — คัมภีร์มอบความเข้าใจในตัว
  (ธีม "ตำราลับถ่ายทอดวิทยายุทธ์ขั้นสูงสุด")
```python
# ค่าตั้งต้น (จูนได้)
MANUAL_SKILL_EXP  = 3000     # skill-EXP ต่อการอ่าน 1 เล่ม
DAILY_REQUEST_CAP = 5        # "แลก/ขอ" คัมภีร์สุดยอดได้สูงสุด 5 ครั้ง/วัน (ไม่ใช่จำกัดการอ่าน)

def request_supreme_manual(player):                 # คอขวด: การได้คัมภีร์
    if player.has_item("supreme_manual_<sect>"):    # ถือได้ครั้งละ 1
        return "มีคัมภีร์ในกระเป๋าแล้ว — อ่านให้หมดก่อนจึงขอใหม่ได้"
    if player.requests_today >= DAILY_REQUEST_CAP:
        return "ครบโควตาแลก/ขอวันนี้"
    if not player.spend_exchange_currency(MANUAL_COST):
        return "ทรัพยากรแลกไม่พอ"
    player.requests_today += 1
    give_bound_item(player, "supreme_manual_<sect>",
                    flags=["character_bound","no_warehouse","no_trade","no_drop","unique_hold_1"])

def read_manual(skill, player):                     # อ่านไม่จำกัดจำนวนครั้ง (ถ้ามีคัมภีร์)
    if not player.consume_item("supreme_manual_<sect>"): return "ไม่มีคัมภีร์ให้อ่าน"
    skill.skill_exp += MANUAL_SKILL_EXP
    while skill.level < 200 and skill.skill_exp >= train_cost(skill.level):
        skill.skill_exp -= train_cost(skill.level); skill.level += 1
```
**ระยะเวลาโดยประมาณ (Lv100→200)** — กำหนดด้วยเพดานการแลก/ขอต่อวัน (เพราะถือได้ทีละ 1):
| รวม skill-EXP (Lv100→200) | คัมภีร์/เล่ม | แลก/ขอ ต่อวัน | EXP สูงสุด/วัน | วันถึง Lv200 |
|---|---|---|---|---|
| ~1,017,345 | 3,000 | 5 ครั้ง | 15,000 | **~68 วัน (~2.3 เดือน)** |
> **เหตุผล:** คุมที่ "การได้มา" ไม่ใช่ "การอ่าน" → ผู้เล่นจะเก็บกดอ่านรวดเดียวไม่ได้ ต้อง
> กลับมาขอรายวัน (login/daily retention) + ถือทีละ 1 + ผูกติดตัว = กัน stockpile/เทรด/มูลขาย
> และคุม power ceiling ให้ Lv100→200 เป็น time-gated endgame ระดับ "ลับสุดยอด" — ป้ายฉายา Lv150/200

## 10. ศิษย์ชั่วชีวิต & วิชาลับประจำสำนัก (Inner Disciple & Secret Arts)

### 10.1 สถานะ "ศิษย์ชั่วชีวิต" (Inner / Lifelong Disciple)
การฝากตัวเป็นศิษย์ชั่วชีวิต = คำมั่นผูกพันกับสำนักเดียวตลอดชีพ (ธีมกำลังภายใน "เข้าห้องลับ")
| หัวข้อ | รายละเอียด |
|---|---|
| เงื่อนไขเข้า | ชื่อเสียง ≥ 4 + contribution สำนักถึงขั้นกำหนด + จบ **"เควสพิธีฝากตัวชั่วชีวิต"** |
| ความผูกพัน | ผูกกับสำนักเดียว — **ออก/ย้ายสำนักได้แต่มีโทษหนัก** (ลบสถานะ + ลืมวิชาลับ + cooldown ยาว) |
| สิทธิ์ที่ปลด | ① เควสรับ **วิชาลับ 3 ท่า** (§10.2) ② ส่วนลดค่าครู/เทคสำนัก ③ เข้าพื้นที่ลับของสำนัก |
| เชื่อมระบบ | ต่อยอดจากระบบอาจารย์–ศิษย์ (docs/06 §7) — ศิษย์ชั่วชีวิตคือขั้นลึกสุดของการเป็นศิษย์ |
> **เหตุผล:** สร้าง "การตัดสินใจผูกมัด" ที่มีน้ำหนัก → เพิ่มอัตลักษณ์สำนัก, ความภักดี,
> และ retention (ผู้เล่นลงทุนกับสำนักจึงไม่อยากทิ้ง) — แต่ยังออกได้ถ้ายอมรับโทษ

### 10.2 วิชาลับ 3 ท่า (ครบ 3 เสา ต่อสำนัก)
หลังเป็นศิษย์ชั่วชีวิต ปลด **3 เควสประจำสำนัก** (เควสละ 1 ท่า) เพื่อรับวิชาลับ — ครบทั้ง
**① โจมตี ② กำลังภายใน(内功) ③ ตัวเบา** เสริมจากวิชาปกติ (เรียนได้ที่ Lv1; เป็นวิชาเฉพาะ
ศิษย์ชั่วชีวิต เรียนข้ามสำนักไม่ได้) — **มีกฎฝึกปรือพิเศษ ดู §10.3**

| สำนัก | ① วิชาลับโจมตี (active) | ② วิชาลับ 内功 (passive) | ③ วิชาลับตัวเบา (passive) |
|---|---|---|---|
| เขาเมฆขาว | กระบี่ลับเทวะเมฆา ⚔ — แทงต่อเนื่อง เจาะป้องกัน | ลมปราณเมฆเทวะ 🌊 — +MP/INT + ฟื้นปราณในรบ | ก้าวเมฆาไร้ร่องรอย 🍃 — +SPD/EVA + พุ่งลัดช่อง |
| วารีบูรพา | ฝ่ามือวารีสลายภพ ✋ — โจมตี+ฟื้นทีมพร้อมกัน | ปราณวารีนิรันดร์ 🌊 — +MP มาก + พลังฟื้นฟู | ลีลาคลื่นพราย 🍃 — +EVA + สลับตำแหน่งกับเพื่อน |
| หุบเขายาพิษ | พิษนรกเจ็ดชั้น ☠ — DoT หนัก + ปิดลมปราณ | กายพิษอมตะ 🌊 — ภูมิพิษเต็ม + +INT | เงาอสรพิษ 🍃 — +SPD + ทิ้งรอยพิษตามทาง |
| กระบองเหล็ก | หมัดทลายขุนเขา ✋ — AoE มึนหนัก | กายวัชระอมตะ 🌊 — +HP/DEF มหาศาล | ย่างมารควาญ 🍃 — +EVA + ภูมิคุ้มผลัก/ตรึง |
| ลมวสันต์ | มีดสายฟ้านิรนาม ⚔ — เบิร์สต์คริติคอลสูง | ปราณวสันต์เร้นกาย 🌊 — +AGI/CRIT | ก้าวลมไร้เงาเร้น 🍃 — +SPD มาก + ออกก่อนรอบแรก |
| วิหารดารา | ลำแสงเจ็ดดารา ✦ — ยิงดารา 7 ลำระยะไกล + ลดต้านทาน | ปราณจักรวาลนิรันดร์ 🌊 — +MP/INT มหาศาล + ฟื้นปราณ | ย่างก้าวดาราเลื่อน 🍃 — +SPD/EVA + วาร์ปสั้นถอยระยะ |

- ยังติดพร้อมใช้ได้ตามข้อจำกัด **active 4 + passive 2** (§5) — วิชาลับเพิ่ม "ตัวเลือกบิลด์"
  ไม่ใช่เพิ่มช่อง → ผู้เล่นต้องเลือกผสมระหว่างวิชาปกติกับวิชาลับ (สร้างความหลากหลาย)
- วิชาลับโจมตี **ไม่ใช่วิชาสืบทอด** (§9) — เป็นคนละสาย; แต่เสริมพลัง/ยูทิลิตี้ให้ศิษย์ที่ทุ่มเท
- **วิชาลับโจมตีใช้รัศมี แบบ 5 (พีระมิด วางจุด) ตั้งแต่ Lv1** (ต่างจากวิชาสืบทอดที่ได้แบบ 5
  ก็ต่อเมื่อแปรร่าง §9) — **ระยะวางโจมตี (cast_range) เพิ่มตามระดับ และสูงสุดที่ Lv100**:
```python
# วิชาลับโจมตี: ทรง=พีระมิด (core 5×5 คงที่); ระยะวางใช้ "สูตรฐานร่วม" (docs/12 §3.3)
# ชั้นระยะ "กลาง": base_range=3, range_growth=0.04, range_cap_level=100
cast_range(level) = 3 + floor(min(level, 100) * 0.04)   # Lv1=3 … Lv100=7 (Lv100–200 คงที่ 7)
```
| ระดับ | Lv1 | Lv30 | Lv50 | Lv70 | Lv90 | Lv100 | Lv200 |
|---|---|---|---|---|---|---|---|
| cast_range (ช่อง) | 3 | 4 | 5 | 5 | 6 | **7 (สูงสุด)** | 7 |
> ช่วง Lv100→200 (อ่านคัมภีร์) **ระยะวางไม่เพิ่มแล้ว** แต่ `skill_mult` (พลังโจมตี) ยังโตต่อ
> (+0.01/ระดับ) — ปลายทางคือ "วางพีระมิดได้ไกลสุด + แรงสุด"

### 10.3 กฎฝึกปรือพิเศษของวิชาลับ (Secret-Art Cultivation Rule)
วิชาลับ **เก่งขึ้นด้วยการฝึกปรือเท่านั้น** มีคุณสมบัติต่างจากวิชาทั่วไป:
- **ไม่ใช้คะแนนเรียน (Combat EXP):** ฝึกฝนทันที (channel ① docs/13) **ใช้ไม่ได้** — ทุ่ม
  Combat EXP เร่งระดับวิชาลับไม่ได้
- **EXP ฝึกปรือเป็นค่าคงที่ + สูงกว่าปกติ:** การฝึกปรือใช้เวลา (channel ②) ให้ skill-EXP เป็น
  **อัตราคงที่** (ไม่ขึ้นกับสถานที่/COM/ธูป) และ **สูงกว่าอัตราฝึกวิชาปกติ**
- **ฝึกปรือได้ถึง Lv100** — จากนั้นต้อง **ขอ/อ่านคัมภีร์** เพื่อดันต่อถึง **Lv200** โดยใช้
  **เงื่อนไขเดียวกับวิชาสุดยอด (§9.5):** จำกัดการแลก/ขอต่อวัน, ถือทีละ 1, ผูกติดตัว
```python
SECRET_FIXED_RATE = 500        # skill-EXP/ชม. คงที่ (สูงกว่า normal baseline 200; ไม่คูณ venue/COM)
def secret_art_cultivate(skill, hours):          # channel ② เท่านั้น
    assert skill.is_secret and skill.level < 100 # >=100 ใช้คัมภีร์ (§9.5)
    skill.skill_exp += SECRET_FIXED_RATE * min(hours, OFFLINE_CAP_HR)
    while skill.level < 100 and skill.skill_exp >= train_cost(skill.level):
        skill.skill_exp -= train_cost(skill.level); skill.level += 1
# instant_drill(skill): ถ้า skill.is_secret -> ปฏิเสธ ("วิชาลับฝึกด้วยคะแนนเรียนไม่ได้")
```
**Pacing:** Lv1→100 รวม ~183,567 EXP ที่ 500/ชม. คงที่ (เพดานออฟไลน์ 12 ชม. = 6,000/วัน)
→ **~31 วัน** ของการบำเพ็ญต่อเนื่อง (เร็วขึ้นถ้าออนไลน์บำเพ็ญด้วย) ต่อวิชาลับ 1 ท่า;
Lv100→200 ผ่านคัมภีร์เพิ่มอีก ~2.3 เดือน (§9.5)
> **คัมภีร์ใช้ร่วม:** "คัมภีร์สุดยอด<สำนัก>" 1 ชนิด อ่านดันได้ทุกวิชา Lv100+ ของสำนัก (วิชา
> สืบทอด §9 และวิชาลับ §10) — โควตาขอต่อวัน **ใช้ร่วมกัน** จึงต้องเลือกว่าจะดันท่าใดก่อน
> **เหตุผล:** วิชาลับ "ซื้อด้วย EXP ไม่ได้" → วัดที่ความทุ่มเทเวลา/ความผูกพันสำนักล้วนๆ
> (เหมาะกับการเป็นรางวัลศิษย์ชั่วชีวิต) และอัตราคงที่สูงทำให้คุ้มค่าที่จะบำเพ็ญสม่ำเสมอ

> **เหตุผลเชิงดีไซน์:** ให้รางวัล "ครบ 3 เสา ชุดที่สอง" แก่ผู้เล่นที่ผูกมัดกับสำนัก →
> ลึกของบิลด์เพิ่ม (มีวิชาให้เลือกใส่ 2 ชุด) โดยช่องติดยังจำกัด = ตัดสินใจมากขึ้น ไม่เฟ้อพลัง

### 10.4 คุณสมบัติพิเศษของวิชาลับ (Secret-Art Traits)
วิชาลับทุกท่ามี **"คุณสมบัติพิเศษ" 1 อย่าง (เลือกอย่างใดอย่างหนึ่งจาก pool)** ที่ **สุ่มทำงาน**
ระหว่างต่อสู้ — โอกาสติด & ความแรงเพิ่มตามระดับวิชา (จึงคุ้มที่จะดันถึง Lv200)
```python
proc_chance(level)  = clamp(0.08 + level*0.0012, 0.08, 0.32)   # Lv1≈8% · Lv100≈20% · Lv200≈32%
effect_power(level) = base_eff + level*eff_growth              # ความแรงเอฟเฟกต์โตตามระดับ
```
**Pool คุณสมบัติพิเศษ (สุ่มติด):**
| รหัส | ชื่อ | ทริกเกอร์ | ผล (โตตามระดับ) |
|---|---|---|---|
| A | สะท้อนปราณ | เมื่อ**ถูกโจมตี** | สุ่มสะท้อนดาเมจกลับ 15→40% |
| B | กายเหล็กฉับพลัน | เมื่อ**ถูกโจมตี** | สุ่มได้บัฟ +DEF 20→50% นาน 2 รอบ |
| C | ปราณทวีคูณ | เมื่อ**ออกท่าโจมตี** | สุ่มเพิ่มความแรงท่าถัดไป +15→40% (ซ้อนได้ 3 ชั้น) |
| D | ดูดปราณ | เมื่อ**โจมตีโดน** | สุ่มดูด HP/MP 10→25% ของดาเมจ |
| E | สุ่มซ้ำสถานะ | เมื่อ**โจมตีโดน** | สุ่มติดสถานะเด่นของวิชาเพิ่ม (พิษ/มึน ฯลฯ) |
| F | หลบสวนเงา | เมื่อ**ถูกโจมตี** | สุ่มหลบหมดดาเมจ + สวนกลับ 1 ครั้ง |
| G | เร่งฝีเท้า | เมื่อ**ออกท่า** | สุ่มเติม Action Gauge +30% / +SPD ชั่วครู่ |

**การกำหนดต่อวิชาลับ (1 ท่า = 1 คุณสมบัติ — ตั้งให้เข้ากับบทบาทสำนัก):**
| สำนัก | โจมตี | 内功 | ตัวเบา |
|---|---|---|---|
| เขาเมฆขาว | C ปราณทวีคูณ | B กายเหล็กฉับพลัน | F หลบสวนเงา |
| วารีบูรพา | D ดูดปราณ | B กายเหล็กฉับพลัน | F หลบสวนเงา |
| หุบเขายาพิษ | E สุ่มซ้ำสถานะ | A สะท้อนปราณ(พิษ) | G เร่งฝีเท้า |
| กระบองเหล็ก | B กายเหล็กฉับพลัน | A สะท้อนปราณ | F หลบสวนเงา |
| ลมวสันต์ | C ปราณทวีคูณ | G เร่งฝีเท้า | F หลบสวนเงา |
| วิหารดารา | C ปราณทวีคูณ | D ดูดปราณ | G เร่งฝีเท้า |
> **เหตุผล:** คุณสมบัติสุ่มทำให้การต่อสู้มี "จังหวะลุ้น" + เสริมบทบาทสำนัก (tank=สะท้อน/เกราะ,
> assassin=เร่ง/ทวีคูณ, พิษ=ซ้ำสถานะ) และให้เหตุผลดันวิชาลับถึง Lv200 (โอกาส/ความแรง proc สูงขึ้น)
> *ตัวเลือกเสริม (ถ้าต้องการความอิสระ):* เปิดให้ผู้เล่น "เลือก" 1 คุณสมบัติจาก 2–3 ตัวเลือกตอนรับวิชา

## 11. วิชาพิเศษนอกสำนัก (Universal Special Arts)
วิชาในตำนานที่ **ไม่สังกัดสำนักใด — ทุกคนเรียนได้** (ไม่จำกัดสำนัก/ฝ่าย) แต่ **หายากมาก**
และให้ **คุณสมบัติเกมเชนจ์** (กลไกพิเศษ ไม่ใช่แค่ +ค่าสถานะ) — ชื่อต้นฉบับ อิงตำนานยุทธภพ

**กติกาส่วนกลาง:**
- **ช่องติดตั้ง: 1 ช่องเฉพาะ** (แยกจาก active4/passive2) → **ติดได้ครั้งละ 1 วิชาเท่านั้น**
  (ทรงพลังมาก จึงเลือกได้อย่างเดียว = ตัดสินใจเชิงบิลด์)
- **เรียนรู้:** จากเควสลับ/NPC พเนจร/สำรวจสถานที่ลับ/บอสโลก/เศษคัมภีร์เทียนจี๋ — ต้อง **COM สูง**
- **ฝึกระดับ 1–100** ตามระบบปกติ (§2–4); โอกาส/ความแรงของกลไกโตตามระดับ
- บางวิชามี **ผลข้างเคียง (drawback)** เพื่อสมดุล (ลดความเสี่ยงเมื่อระดับสูงขึ้น)

| วิชา (ต้นฉบับ) | อาร์คีไทป์ | คุณสมบัติพิเศษ (โตตามระดับ) | ข้อจำกัด/ผลข้างเคียง |
|---|---|---|---|
| **เคล็ดสองกระบวนพิศวง** | สองมือขัดแย้ง | ร่าย active **2 ท่าในจังหวะเดียว** (ท่าที่ 2 ดาเมจ ×0.5→0.8) | จ่ายลมปราณทั้งสองท่า |
| **วิชาพลิกหยินหยางจักรวาล** | เคลื่อนย้ายพลัง | กดกัน/แปลงดาเมจที่รับ 20→50% เป็น **MP/HP** + โอนดีบัฟคืนศัตรู | cooldown หลายรอบ |
| **เคล็ดยืมพลังพลิกดารา** | สะท้อน/ย้อนแรง | ถูกโจมตี → สุ่ม 10→40% **สะท้อนท่ากลับด้วยพลังศัตรูเอง** | ได้ผลดีกับท่าเดี่ยวแรง |
| **มหาวิชาสูบกลืนปราณ** | ดูดปราณ | โจมตี → **ดูด MP ศัตรู** มาเป็นของตน + สุ่มปล้นบัฟ 1 ชั้น | **ปราณแปรปรวน:** สุ่มรับดาเมจย้อน/เสียตา ถ้าระดับต่ำ (ลดตามระดับ) |

```python
# ค่าตัวอย่าง (level 1..100) — จูนได้
twin_second_mult  = 0.5 + level*0.003                       # ท่าที่สองของ "สองกระบวน": Lv1 .50 → Lv100 .80
cosmos_convert    = clamp(0.20 + level*0.003, 0.20, 0.50)   # พลิกจักรวาล: แปลงดาเมจ 20→50%
star_reflect_pct  = clamp(0.10 + level*0.003, 0.10, 0.40)   # ยืมพลังพลิกดารา: โอกาสสะท้อน
devour_mp         = round(20 + level*1.3)                   # สูบกลืนปราณ: MP ที่ดูดต่อครั้ง
devour_backlash   = clamp(0.25 - level*0.002, 0.05, 0.25)   # ผลข้างเคียง ลดตามระดับ (Lv100 ≈ 5%)
```
> **เหตุผลเชิงดีไซน์:** วิชาพิเศษเป็น "ของในตำนาน" ที่ปรับสไตล์การเล่นทั้งเส้น (เบิร์สต์สองท่า /
> สายกัน-แปลง / สายสะท้อน / สายดูดปราณ) — ติดได้ทีละ 1 + หายาก → เป็นเป้าหมายล่าระยะยาว (chase)
> และเปิดบิลด์ลูกผสมข้ามสำนักโดยไม่พังสมดุล (มี drawback/ช่องจำกัดคุมไว้)
> *ลิขสิทธิ์:* ชื่อ/กลไกออกแบบใหม่ทั้งหมด — อิงแนวอาร์คีไทป์ยุทธภพ ไม่คัดลอกผลงานลิขสิทธิ์ใด
