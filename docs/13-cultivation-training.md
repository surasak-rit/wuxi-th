# 13 — ระบบฝึกปรือวิทยายุทธ (Martial Cultivation / Training System)

> "วิธีลงมือฝึก" จริง — รวมทุกช่องทางที่ป้อน **skill-EXP** เข้าวิชาเพื่อดันระดับ (Lv 1–100/200)
> ต่อยอดจาก docs/02: §2–3 (สูตร `train_cost(L)`, ความชำนาญ), §4 (COM gate), §9 (ด่านสืบทอด/คัมภีร์)
> **ทุกช่องทางป้อน skill-EXP เข้ากองเดียวกัน** แล้วเลื่อนระดับด้วย `train_cost(L)=round(2*L^1.7)`

---

## 1. สามช่องทางฝึกปรือ (3 Channels → skill-EXP)
| ช่องทาง | ได้ skill-EXP จาก | ต้นทุน | จุดเด่น |
|---|---|---|---|
| ① ฝึกฝนทันที (Instant Drill) | แปลง **Combat EXP** ที่สะสม → skill-EXP ทันที (กดฝึก) | Combat EXP (เพดานชื่อเสียง) | เร่งได้เร็วถ้าฟาร์มมา |
| ② ฝึกปรือใช้เวลา (Timed Cultivation) | **เวลาจริง** (ปักหลักบำเพ็ญ ออน/ออฟไลน์) | เวลา + พลังบำเพ็ญ | baseline ฟรี ไหลเรื่อยๆ |
| ③ ความชำนาญจากการใช้จริง (Proficiency) | **ใช้วิชาในรบ** สะสม prof | ใช้จริงในการต่อสู้ | ลดต้นทุน + โบนัส |
```
                ┌─ ① Combat EXP (กดฝึก) ─┐
วิชา.skill_exp ←─┼─ ② Timed cultivation ──┼→  while skill_exp >= train_cost(L): level++
                └─ ③ Proficiency bonus ──┘     (กดด้วย COM gate §4 + ด่าน §3.4)
```
> **เหตุผล:** ผู้เล่นสายฟาร์มเน้น ① / ผู้เล่นเวลาน้อยพึ่ง ② (ออฟไลน์) / ทุกคนได้ ③ จากการเล่นปกติ
> — ทุกสไตล์มีทางก้าวหน้า ไม่บังคับทางเดียว

---

## 2. ① ฝึกฝนทันที (Instant Drill)
- ที่จุดฝึก กด "ฝึก" → จ่าย Combat EXP ตาม `train_cost(L)` ได้ระดับทันที (เท่ากับ docs/02 §3 ข้อ 1)
- อัตราแปลง 1:1 (Combat EXP → skill-EXP) แต่ติดเพดาน Combat EXP สะสม (ชื่อเสียง, docs/03 §3)
- เหมาะ "ทุ่มทีเดียว" หลังฟาร์ม/ตีบอสมาเต็มกระเป๋า

## 3. ② ฝึกปรือใช้เวลา (Timed Cultivation / ปักหลักบำเพ็ญ)
มอบหมายวิชาให้ "บำเพ็ญ" แล้วได้ skill-EXP ตามเวลาจริง — ทำงานทั้งตอนออนไลน์ (idle) และสะสม
ตอนออฟไลน์ (จนถึงเพดาน)
```python
BASE_RATE       = 200        # skill-EXP ต่อชั่วโมง (ฐาน)
OFFLINE_CAP_HR  = 12         # สะสมออฟไลน์ได้สูงสุด 12 ชม.
def cultivation_rate(venue, COM, incense=False):
    rate = BASE_RATE * VENUE_MULT[venue] * (1 + COM*0.005)   # COM เร่งการฝึก
    if incense: rate *= 1.5                                  # ธูปสมาธิ (consumable)
    return rate                                              # skill-EXP/ชม.
```
**ช่อง bulk:** บำเพ็ญพร้อมกันได้ **1 วิชาหลัก** (เริ่มต้น) → ปลดเพิ่มตามชื่อเสียง (สูงสุด 3)
**พลังบำเพ็ญ (Cultivation Stamina):** ฟื้นเต็มทุกวัน — ② กินพลังบำเพ็ญ; หมดแล้วอัตราตก 50%
(soft cap กันฝึก 24 ชม.ติด โดยไม่ปิดกั้น) — ค่าเริ่มต้นพอ ~12 ชม./วัน

### 3.1 ตารางสถานที่ฝึก (Venue) & อัตรา
| สถานที่ | mult | skill-EXP/ชม.* | เงื่อนไข |
|---|---|---|---|
| ภาคสนาม/ป่า | 0.8 | ~192 | ที่ไหนก็ได้ (ฝึกควบฟาร์ม) |
| ที่พัก/บ้าน | 1.2 | ~288 | มีบ้าน (docs/09 §4) |
| ลานฝึก/ห้องบำเพ็ญสำนัก | 1.5 | ~360 | สมาชิกสำนัก |
| จุดมงคลลับ (น้ำตก/ยอดเขา/ถ้ำ) | 2.5 | ~600 | จำนวนจำกัด — **แย่ง/จองในโลกเปิด** (อาจปะทะ PvP) |
> *คำนวณที่ COM 40; COM สูงเร่งเพิ่ม (COM 80 ≈ +40%). 12 ชม.ออฟไลน์ที่ลานสำนัก ≈ 4,320 exp
> (ช่วงต้นไต่ ~Lv1→25 รวดเดียว; ปลายเกม Lv90→91 ใช้ ~6 ชม.ที่จุดมงคลลับ) — ② เป็น baseline
> ไวช่วงต้น/หน่วงช่วงปลาย เสริมกับ ① ที่เร่งด้วยการฟาร์ม

## 4. ③ ความชำนาญ (Proficiency) — ดู docs/02 §3
- ใช้วิชาในรบสะสม `prof`; เต็มแถบ (`prof_to_next(L)=20+L*3`) → **ระดับถัดไปลดต้นทุน 20%** + แถม skill-EXP ก้อนเล็ก
- จูงใจ "ใช้วิชาที่ฝึกจริง" — บิลด์ที่เล่นสม่ำเสมอคุ้มกว่าการกดซื้อระดับล้วน

## 5. การทะลวงด่าน (Breakthrough / ติดขั้นบำเพ็ญ)
วิทยายุทธ์มี "ด่าน" ที่ต้องทะลวงก่อนไปต่อ — สื่อความรู้สึกกำลังภายในแบบ JY
| ด่าน | ระดับ | วิธีทะลวง | ผลถ้าพลาด |
|---|---|---|---|
| ด่านย่อย (minor) | ทุก Lv ลงท้าย 0 (10,20,…) | นั่งสมาธิสั้นๆ (ฟรี) — โอกาสสำเร็จสูง (เพิ่มตาม COM) | เสียเวลาเล็กน้อย ลองใหม่ได้ |
| ด่านเกรด (grade-cap) | 70 / 80 / 90 (เพดาน grade) | ใช้ไอเทม **"เคล็ดทะลวงด่าน"** + นั่งสมาธิ | เสียไอเทม, ระดับไม่ตก, ลองใหม่ได้ |
| ด่านสืบทอด | 30 / 70 / 100 | ตามเส้นทาง §9 (อาจารย์/เควส) | — (เป็น gate) |
```python
def breakthrough(skill, player):
    chance = clamp(BASE_BT + player.COM*0.004 + item_bonus, 0.30, 0.99)  # COM ช่วยทะลวง
    if roll() <= chance:
        skill.breakthrough_done[skill.level] = True   # ปลดให้ฝึกข้ามด่านต่อได้
    else:
        consume_resources_partial()                   # เสียทรัพยากรบางส่วน ไม่เสียระดับ
```
> **เหตุผล:** ด่านสร้างจังหวะ "ความสำเร็จเป็นช่วง" (milestone) + เป็น sink ของไอเทม/เวลา และทำให้
> COM มีคุณค่าเพิ่ม (เร่งทะลวง) — ผูกกับธีม "ฝึกจนแตกฉานทะลุขั้น"

## 6. ฝึกร่วม & อาจารย์ชี้แนะ (Co-op / Master Guidance)
- **ประลองคู่ฝึก (Sparring):** ดวลกับเพื่อน/ศิษย์ร่วมสำนัก (ไม่เสียของ) → ทั้งคู่ได้ **prof ②x** เร็วขึ้น
- **อาจารย์ชี้แนะ:** ศิษย์ (โดยเฉพาะศิษย์ชั่วชีวิต §10) ฝึกใกล้ NPC/ผู้เล่นอาจารย์ → **+อัตราฝึก**
  และปลดด่านเกรดง่ายขึ้น — ผูกระบบอาจารย์–ศิษย์ (docs/06 §7) เข้ากับการฝึก
- **บำเพ็ญหมู่ในสำนัก:** หลายคนบำเพ็ญพร้อมกันในห้องบำเพ็ญสำนัก → บัฟอัตรากลุ่ม (สังคม/retention)

---

## 7. ตัวเร่ง & sinks (Accelerators)
| ไอเทม/บริการ | ผล | ต้นทุน (sink) |
|---|---|---|
| ธูปสมาธิ | +50% อัตรา ② ช่วงเวลาหนึ่ง | เงิน/คราฟต์ |
| เคล็ดทะลวงด่าน | จำเป็นสำหรับด่านเกรด (§5) | drop/แลก contribution |
| ตำราเสริม (one-time) | skill-EXP ก้อนเดียว | drop/ซื้อ |
| เช่าจุดมงคลลับ (premium) | ใช้สิทธิ์ฝึกจุด mult สูง | เงิน/ตั๋วสำนัก |
| คัมภีร์สุดยอด | ดัน Lv100→200 (เฉพาะวิชาสุดยอด) | §9.5 (จำกัด/วัน, ผูกติดตัว) |

## 8. การเชื่อมกับระบบอื่น (Integration)
- **Gate ทับซ้อน:** การฝึกทุกช่องยังติด `level_cap = ⌊COM×1.25⌋` (docs/02 §4) + เพดานด่านสืบทอด
  (30/70/100, docs/02 §9) — ① ② ③ ทั้งหมดเป็น "ฝึกเอง" จึงตันที่ด่านจนกว่าจะปลด (อาจารย์/เควส)
- **Combat EXP ↔ ชื่อเสียง:** ① ใช้ Combat EXP ซึ่งมีเพดานตามชื่อเสียง (docs/03 §3) → เชื่อม core loop
- **เศรษฐกิจ:** ธูป/เคล็ดทะลวงด่าน/เช่าจุดฝึก = gold/contribution sink (docs/05 §8)
- **PvP โลกเปิด:** จุดมงคลลับจำกัด → เป็นทรัพยากรให้แย่งชิง (docs/06)

## 9. สรุป Loop การฝึกปรือ
```
ฟาร์ม/ตีบอส → ได้ Combat EXP ──① กดฝึก──┐
ปักหลักบำเพ็ญ (เวลา/ออฟไลน์) ──②────────┤→ skill_exp → เลื่อนระดับ → ติดด่าน
ใช้วิชาในรบ → prof ──③──────────────────┘                          │
                                                    ทะลวงด่าน (สมาธิ/ไอเทม/อาจารย์/เควส)
                                                                    │
                                              วิชาแกร่งขึ้น → ฟาร์ม/บอส/PvP ยากขึ้น (วนกลับ)
```
> ทุกช่องทางป้อน skill-EXP กองเดียว แต่มี **gate หลายชั้น** (COM / ด่าน / ชื่อเสียง) คุมจังหวะ —
> ทำให้การฝึกปรือเป็นกิจกรรมแกนที่ผูกเข้ากับฟาร์ม สังคม เศรษฐกิจ และเนื้อเรื่องทั้งหมด
