# 15 — ระบบสเตตัสตัวละคร (Character Stats System) — โมเดล 7 ค่าแบบ JY Online

> อ้างอิง JY Online (มังกรหยกออนไลน์): ตัวละครมี **ค่าพื้นฐานที่แจกได้ 7 ค่า** เท่านั้น
> ส่วน เลือด/ลมปราณ/พลังโจมตี/ป้องกัน ฯลฯ เป็น **ค่าที่คำนวณได้ (derived)** จาก 7 ค่านี้
> เอกสารนี้เป็น **แหล่งนิยามค่าพื้นฐาน+derived ที่เป็น canonical** (แทนที่ STR/INT/AGI/FOC เดิม)

---

## 1. ค่าพื้นฐาน 7 ค่า (Primary Attributes) — มีผลอะไรบ้าง
เพดานต่อค่า = 100 (เริ่มแจกตอนสร้างตามสำนัก, โตจากการเล่นจริง §3)
| ค่า | สัญลักษณ์ | ส่งผลต่อ (derived/ระบบ) |
|---|---|---|
| **กำลังแขน** | ARM | **พลังโจมตีภายนอก** (กระบี่/ดาบ/หมัด/กาย), น้ำหนักแบกของ |
| **กระดูก** | BON | **เลือด (HP)**, รากฐาน **ลมปราณ (MP)**, **ป้องกัน (DEF)** |
| **ปฏิภาณ** | AGI | **ฝีเท้า/SPD** (จังหวะ ATB), ความเร็วเดินกริด, **แม่นยำ (ACC)**, **หลบหลีก (EVA)** |
| **ความกล้า** | CRG | **พลังโจมตีภายใน** (วิชาลมปราณ/พิษ/เวท), **คริติคอล**, ลมปราณเสริม |
| **รู้แจ้ง** | COM | **เพดานระดับวิชา** (`⌊รู้แจ้ง×1.25⌋`), อัตรา/ทะลวงด่านฝึกปรือ, เพดานวิชาลับ/ธาตุ |
| **ฟื้นฟู** | REC | **อัตราฟื้น HP/ลมปราณ** (regen ในและนอกรบ), เสริม HP/DEF, ต้านสถานะบางส่วน |
| **วาสนา** | FOR | **โชค:** อัตรา drop/ของหายาก, โอกาสคริติคอลเสริม, เหตุการณ์ดี/พรวันเกิด, ปลดภารกิจวิชาพิเศษ |

> **หมายเหตุ JY:** "รู้แจ้ง" = ฝึกวิชาเร็ว/เพดานสูง (= COM เดิม); "ความกล้า/วาสนา/ฟื้นฟู/ปฏิภาณ"
> มักเป็นเงื่อนไขขั้นต่ำของภารกิจวิชาพิเศษ (เช่น วาสนา≥19, ฟื้นฟู≥20, ปฏิภาณ≥21, ความกล้า≥25)

## 2. ค่าสถานะที่คำนวณได้ (Derived Stats) — สูตร canonical
```python
เลือด (HP)        = 50 + กระดูก*12 + ฟื้นฟู*3
ลมปราณ (MP)       = 30 + กระดูก*4 + ความกล้า*7          # internal force
พลังโจมตีภายนอก   = กำลังแขน*2.5 + อาวุธ                 # วิชากาย/กระบี่/หมัด ใช้ค่านี้
พลังโจมตีภายใน    = ความกล้า*2 + กระดูก*0.5 + อาวุธเวท   # วิชาลมปราณ/พิษ/เวท ใช้ค่านี้
ป้องกัน (DEF)     = กระดูก*1.2 + ฟื้นฟู*0.3 + เกราะ
ความแม่นยำ (ACC)  = ปฏิภาณ*1.5
การหลบหลีก (EVA)  = ปฏิภาณ*1.2
ฝีเท้า (SPD)      = ปฏิภาณ*2 + ความกล้า*0.3              # → จังหวะ ATB (docs/11)
คริติคอล (CRIT)   = 5% + ความกล้า*0.15% + วาสนา*0.1%     # เพดาน 50%
regen/tick        = HP: 1+ฟื้นฟู*0.15 · MP: 1+ฟื้นฟู*0.1 # (เร่งตอนนั่งสมาธิ docs/01 §9)
find_rate         = 1.0 + วาสนา*0.004                    # โอกาส drop/ของหายาก
```
**ตัวอย่างตัวละครใหม่** (ทุกค่า = 5): HP=125, MP=85, ATKภายนอก=12.5, DEF=7.5, SPD=11.5, CRIT≈6.25%
> สเกลใกล้เคียงโมเดลเดิม — **"พลังโจมตี" แยกภายนอก/ภายใน** ตามชนิดวิชา (กาย vs ลมปราณ) แบบ JY:
> วิชากายภาพอ่านจากกำลังแขน, วิชาลมปราณ/พิษ/เวทอ่านจากความกล้า

### 2.1 การแมปค่าเดิม → 7 ค่า (Legacy Mapping)
เอกสารอื่น (docs/01 §3–4, docs/02 req วิชา) ที่ยังเขียน STR/INT/AGI/FOC ให้อ่านตามแมปนี้:
| เดิม | → 7 ค่าใหม่ |
|---|---|
| STR (พลัง) | **กำลังแขน** (โจมตีภายนอก) — ส่วน HP ย้ายไป **กระดูก** |
| INT (ภายใน) | **ความกล้า** (โจมตีภายใน) + **กระดูก** (ลมปราณ) |
| AGI (ว่องไว) | **ปฏิภาณ** |
| FOC (สมาธิ) | กระจายเป็น **กระดูก**(DEF) + **ความกล้า**(CRIT) + **ฟื้นฟู**(regen/ต้านสถานะ) |
| COM (ความเข้าใจ) | **รู้แจ้ง** |
| — (ใหม่) | **วาสนา** (โชค), **ฟื้นฟู** (regen) = ค่าที่โมเดลเดิมไม่มีแยก |
> สูตรดาเมจ/hit/crit ใน docs/01 §4 ยังใช้ได้ (อ้าง ATK/DEF/ACC/EVA/SPD/CRIT ที่เป็น derived) —
> เปลี่ยนแค่ "ที่มา" ของค่าเหล่านั้นเป็น 7 ค่าตามตารางข้างบน

## 3. วิธีเพิ่มค่าพื้นฐาน (ทุกช่องทาง)
| วิธี | ชนิด | รายละเอียด |
|---|---|---|
| ① ฝึกด้วย Combat EXP | ถาวร | `attrCost(v)=round(50*v^1.6)` ต่อ +1 (docs/03 §4.2) — ช่องทางหลัก |
| ② ฝึกเฉพาะทาง (JY-style) | ถาวร | บางค่าขึ้นจากกิจกรรมตรง: กำลังแขน↑จากต่อสู้มือเปล่า, กระดูก↑จากฝึก 内功, ปฏิภาณ↑จากฝึกตัวเบา/หลบ, รู้แจ้ง↑จากอ่านตำรา |
| ③ วิชากำลังภายใน 内功 (passive) | กึ่งถาวร | +ลมปราณ/HP/ค่าพื้นฐานตามระดับวิชา (docs/02 §7) |
| ④ ยาบำรุง/ของเสวยถาวร | ถาวร | ของหายาก +flat ถาวร / เพิ่มเพดาน |
| ⑤ อุปกรณ์ + หยกสลัก + ตีบวก | ชั่วคราว | ตามที่สวม (docs/05) |
| ⑥ เควส/เนื้อเรื่อง/เศษคัมภีร์ | ถาวร | แหล่งหลักของ **รู้แจ้ง (COM)** + ปลดเพดานบางค่า |
| ⑦ ฉายา/achievement/ชื่อเสียง | ถาวร (เล็ก) | โบนัสจากความสำเร็จ |
| ⑧ **พรวันเกิด (สุ่ม)** | ถาวร | สุ่มเพิ่มรายปีเกม — ดู §4 |
| ⑨ อาหารปรุง/บัฟบ้าน-สวน/ธูป | ชั่วคราว | บัฟช่วงเวลา (docs/14, 09, 13) |
> ลำดับคำนวณค่าจริง: ฐาน(7 ค่า) → +flat อุปกรณ์/หยก → ×(1+Σ passive%) → +บัฟชั่วคราว → clamp (docs/10 §7)

## 4. ระบบสุ่มพรวันเกิด (Birthday Random Bonus)
ตัวละครมี **วันเกิด + ดวงประจำตัว** (กำหนดตอนสร้าง) — ทุกครบ **รอบปีเกม** ได้ **"พรวันเกิด"**
สุ่มเพิ่มค่าพื้นฐาน **ถาวร** (ปีละ 1 ครั้ง/ตัวละคร; ผูกปฏิทินในเกม กันการปั่นเวลา)

### 4.1 ดวงประจำตัว (Birth Sign) — ผูกธีมสามดวง (ถ่วงน้ำหนักการสุ่ม)
| ดวง | เอนเอียง (ค่าที่พรออกบ่อยกว่า) |
|---|---|
| ☀ **ดวงตะวัน** | กำลังแขน / กระดูก (สายกาย/พลัง) |
| ✦ **ดวงดารา** | ปฏิภาณ / วาสนา (ว่องไว/โชค) |
| ☾ **ดวงจันทรา** | ความกล้า / รู้แจ้ง / ฟื้นฟู (ปราณ/ปัญญา) — ลุ้นรู้แจ้ง(COM) ง่ายขึ้นเล็กน้อย |

### 4.2 ตารางสุ่มพร (ต่อรอบปีเกม)
| ระดับพร | โอกาส | ผล (ถาวร) |
|---|---|---|
| ธรรมดา | 60% | **+1** หนึ่งค่า (สุ่มตามน้ำหนักดวง) |
| ดี | 25% | **+2** หนึ่งค่า |
| หายาก | 12% | **+1 สองค่า** หรือ **+3 หนึ่งค่า** |
| มงคล (มหาฤกษ์) | 3% | **+1 รู้แจ้ง(COM)** หรือ **+2 สองค่า** |
```python
def birthday_blessing(char):
    tier = weighted_roll({"ธรรมดา":.60,"ดี":.25,"หายาก":.12,"มงคล":.03})
    if tier=="มงคล" and roll()<0.5: char.รู้แจ้ง = min(100, char.รู้แจ้ง+1)   # โบนัส COM พิเศษ
    else: apply_stat_gain(tier, weights=char.birth_sign.weights)            # +ค่าพื้นฐานตามดวง
    grant_birthday_gift(char)   # + ของขวัญ (ไอเทม/ฉายาประจำปี/บัฟ +EXP 24ชม.)
# คาดหวัง ~1.4 แต้ม/ปี (ฟรี เทียบ attrCost ที่ยิ่งแพง); เกิน cap 100 → แปลงเป็นไอเทม
```
> **เหตุผล:** วันเกิด = จุดผูกใจรายปี (retention) + แหล่งรู้แจ้ง(COM) ทางเลือกที่หายาก;
> "ดวงประจำตัว" เพิ่มอัตลักษณ์ + ผูกธีมสามดวง (ตะวัน/ดารา/จันทรา) ที่ใช้ทั่วเกม (ธาตุอาชีพ docs/14)

## 5. การเชื่อมระบบ
- **PI (docs/03 §6):** ผลรวมค่าพื้นฐานถาวร (7 ค่า, รวมพรวันเกิด) นับเข้า PI — เพดานรวม 700 (7×100)
- **ฝึกปรือ (docs/13):** รู้แจ้งเร่งฝึก/ทะลวงด่าน; ฟื้นฟูเร่ง regen ระหว่างพัก
- **วิชา:** วิชากายอ่านโจมตีภายนอก(กำลังแขน), วิชาลมปราณ/พิษ/เวทอ่านโจมตีภายใน(ความกล้า)
- **โชค (วาสนา):** เพิ่ม drop/ของหายาก (docs/05/08) + ปลดภารกิจวิชาพิเศษ (docs/02 §11 แนว JY)
