## 1. ค่าพื้นฐาน (Primary Attributes) — มีผลอะไรบ้าง
ค่าพื้นฐาน 4 + ค่าความเข้าใจ (เพดานต่อค่า = 100; COM ก็ 100)
| ค่า | ส่งผลต่อ (derived/ระบบ) |
|---|---|
| **STR** พลัง | **HP** (×12), **ATK** (×2) — สายกาย/ดาเมจกายภาพ |
| **INT** ภายใน | **MP** (×10), **ATK วิชา** (×1), พลังฟื้นฟู/พิษ/เวท, regen ลมปราณ |
| **AGI** ว่องไว | **SPD** (×2 → จังหวะ ATB docs/11), **ความเร็วเดินบนกริด**, **ACC** (×1.5), **EVA** (×1.2) |
| **FOC** สมาธิ | **DEF** (×1.5), **CRIT** (+0.2%/แต้ม), HP/MP เสริม, **ต้านสถานะ** (status_res), regen สมาธิ |
| **COM** ความเข้าใจ | **เพดานระดับวิชา** (`⌊COM×1.25⌋`), อัตรา/โอกาสทะลวงด่านฝึกปรือ (docs/13), เพดานวิชาลับ/ธาตุ |

## 2. ค่าสถานะที่ได้ (Derived Stats) — สูตรย่อ (เต็มที่ docs/01 §3)
```
HP = 50 + STR*12 + FOC*3      MP = 30 + INT*10 + FOC*2
ATK = STR*2 + INT + อาวุธ      DEF = FOC*1.5 + AGI*0.5 + เกราะ
ACC = AGI*1.5 + FOC*0.5       EVA = AGI*1.2
SPD = AGI*2 + FOC*0.5         CRIT = 5% + FOC*0.2% (เพดาน 50%)
```

## 3. วิธีเพิ่มค่าพื้นฐาน (ทุกช่องทาง)
แยก **ถาวร (permanent)** กับ **ชั่วคราว/ตามอุปกรณ์ (temporary)**
| วิธี | ชนิด | รายละเอียด |
|---|---|---|
| ① ฝึกด้วย Combat EXP | ถาวร | `attrCost(v)=round(50*v^1.6)` ต่อ +1 (แพงขึ้นตามค่า) — ช่องทางหลัก (docs/03 §4.2) |
| ② วิชากำลังภายใน 内功 (passive) | กึ่งถาวร | +INT/HP/MP/SPD ฯลฯ ตามระดับวิชาที่ติด (docs/02 §7) |
| ③ ยาบำรุง/ของเสวยถาวร | ถาวร | ของหายาก (โสมพันปี ฯลฯ) +flat ถาวรเล็กน้อย / เพิ่มเพดาน |
| ④ อุปกรณ์ + หยกสลัก + ตีบวก | ชั่วคราว (ตามที่สวม) | อาวุธ/เกราะ/เครื่องประดับ + หยก (docs/05) |
| ⑤ เควส/เนื้อเรื่อง/เศษคัมภีร์ | ถาวร | **แหล่งหลักของ COM** (จงใจหายาก, docs/02 §4) |
| ⑥ ฉายา/achievement/ชื่อเสียง | ถาวร (เล็ก) | โบนัสเล็กน้อยจากความสำเร็จ |
| ⑦ **พรวันเกิด (สุ่ม)** | ถาวร | สุ่มเพิ่มรายปีเกม — ดู §4 |
| ⑧ อาหารปรุง/บัฟบ้าน-สวน/ธูป | ชั่วคราว | บัฟช่วงเวลา (docs/14, docs/09, docs/13) |
> **ลำดับคำนวณค่าจริง** (docs/10 §7): ฐานจากค่าพื้นฐาน → +flat อุปกรณ์/หยก → ×(1+Σ passive%) →
> +บัฟ/ดีบัฟชั่วคราว → clamp (เช่น CRIT ≤ 50%)
> **ถาวร (①③⑤⑥⑦)** สะสมเข้าค่าพื้นฐานจริง (นับใน PI); **ชั่วคราว (②④⑧)** ผูกกับสิ่งที่ติด/บัฟ

## 4. ระบบสุ่มพรวันเกิด (Birthday Random Bonus)
ตัวละครมี **"วันเกิด" + "ดวงประจำตัว"** กำหนดตอนสร้าง — ทุกครบ **รอบปีเกม** (in-game year)
จะได้ **"พรวันเกิด"** สุ่มเพิ่มค่าพื้นฐาน **ถาวร** (รับได้ปีละ 1 ครั้ง/ตัวละคร)
> ผูกปฏิทินในเกม (ไม่ใช่วันจริง) → จังหวะสม่ำเสมอ, กันการปั่นเวลา; โบนัสเล็ก (~1.4 แต้ม/ปี)
> เทียบกับการฝึกเอง (attrCost แพงขึ้นเรื่อยๆ) จึงเป็น "ของขวัญเสริม" ที่มีค่าแต่ไม่พังสมดุล

### 4.1 ดวงประจำตัว (Birth Sign) — เลือกตอนสร้าง (ผูกธีมสามดวง)
| ดวง | เอนเอียง (passive เล็ก + ถ่วงน้ำหนักสุ่มพร) |
|---|---|
| ☀ **ดวงตะวัน** | สาย STR/FOC (กาย/พลัง) — พรวันเกิดออก STR/FOC บ่อยกว่า |
| ✦ **ดวงดารา** | สาย AGI (ว่องไว/คริติคอล) — พรออก AGI/FOC บ่อยกว่า |
| ☾ **ดวงจันทรา** | สาย INT/COM (ปัญญา/ปราณ) — พรออก INT บ่อยกว่า + ลุ้น COM ง่ายขึ้นเล็กน้อย |

### 4.2 ตารางสุ่มพร (ต่อรอบปีเกม)
| ระดับพร | โอกาส | ผล (ถาวร) |
|---|---|---|
| ธรรมดา | 60% | **+1** หนึ่งค่าพื้นฐาน (สุ่มตามน้ำหนักดวง) |
| ดี | 25% | **+2** หนึ่งค่าพื้นฐาน |
| หายาก | 12% | **+1 สองค่า** หรือ **+3 หนึ่งค่า** |
| มงคล (มหาฤกษ์) | 3% | **+1 COM** (หายากมาก!) หรือ **+2 สองค่า** |
```python
def birthday_blessing(char):
    tier = weighted_roll({"ธรรมดา":.60,"ดี":.25,"หายาก":.12,"มงคล":.03})
    if tier=="มงคล" and roll()<0.5: char.COM = min(100, char.COM+1)       # โบนัส COM พิเศษ
    else: apply_stat_gain(tier, weights=char.birth_sign.weights)           # +ค่าพื้นฐานตามดวง
    grant_birthday_gift(char)   # + ของขวัญ (ไอเทม/ฉายาประจำปี/บัฟชั่วคราว)
# คาดหวัง ~1.4 แต้ม/ปี; ค่าพื้นฐาน cap 100 ตามเดิม (พรที่เกิน cap → แปลงเป็นของขวัญแทน)
```
- **ของขวัญวันเกิดเสริม** (ทุกครั้ง): กล่องของขวัญ (วัตถุดิบ/ยา), บัฟ "วันเกิด" ชั่วคราว (+EXP/+อัตราฝึก 24 ชม.),
  และทุกปีที่ 5/10 ได้ **ฉายาวันเกิด** พิเศษ (prestige)
- **พรที่เกินเพดาน** (ค่าถึง 100 แล้ว): แปลงเป็นไอเทม/เงินแทน (ไม่เสียเปล่า)

> **เหตุผลเชิงดีไซน์:** วันเกิด = จุดผูกใจรายปี (retention/อารมณ์ผูกพันตัวละคร) + แหล่ง COM ทางเลือก
> ที่หายากเพิ่มอีกทาง; "ดวงประจำตัว" เพิ่มอัตลักษณ์ตัวละครและผูกธีมสามดวง (ตะวัน/ดารา/จันทรา)
> ที่ใช้ทั่วทั้งเกม (ระบบธาตุอาชีพ docs/14, ลอร์ docs/07)

## 5. การเชื่อมระบบ
- **PI (docs/03 §6):** ค่าพื้นฐานถาวร (รวมพรวันเกิด) นับเข้า PI โดยตรง
- **ฝึกปรือ (docs/13):** COM เร่งอัตราฝึก/ทะลวงด่าน → พรวันเกิดสาย COM มีค่าทบต้น
- **ธาตุ/ดวง:** ดวงประจำตัวผูกธีมสามดวงเดียวกับธาตุอาชีพ (docs/14) — อาจให้โบนัสเล็กน้อยข้ามระบบ (optional)
- **อุปกรณ์/passive:** ค่าชั่วคราวไม่นับในพรวันเกิด/PI ถาวร (แยกชั้นชัดเจน)
