## 1. ปรัชญาการต่อสู้
เกมนี้ใช้ระบบต่อสู้ **Real-time บนกริด + Action Gauge (ATB)** เป็นระบบหลัก (docs/11) —
ผู้เล่นเคลื่อนที่จัดตำแหน่งและสั่งท่าตามจังหวะที่หลอดเต็ม โดยยังเปิดให้ตั้ง **แผนการรบ/
สคริปต์อัตโนมัติ** ช่วยได้ (§6) มรดกจาก JY Online ที่คงไว้คือ "หัวใจอยู่ที่การเตรียมตัว
ก่อนรบ" (จัดวิชา/ลำดับท่า/ไอเทม/ค่าพลัง) ผสานกับ **การวางตำแหน่งแบบ real-time**

> **เหตุผลเชิงดีไซน์:** real-time + positioning เพิ่มความมันของการล้างฝูง (docs/11) ขณะที่
> auto-script ยังรองรับผู้เล่นมือถือ/เน็ตช้า และทำให้ "การฝึกวิชา/จัดบิลด์" (เมตาหลักของเกม)
> ยังเป็นตัวตัดสินผลแพ้ชนะอย่างแท้จริง ไม่ใช่รีเฟล็กซ์ล้วน

## 2. ลำดับการประมวลผลใน 1 รอบ (Turn Resolution Order)
```
สำหรับแต่ละรอบ (Round):
  1. คำนวณ SPD ปัจจุบันของทุกตัว (รวมบัฟ/ดีบัฟ/เอฟเฟกต์ท่า)
  2. เรียงคิวออกท่าจาก SPD มาก → น้อย (เท่ากัน = สุ่ม)
  3. ทีละตัวในคิว:
     a. ตรวจสถานะคุม (มึน/ตรึง/หลับ) → ถ้าติด ข้ามตา / ทำได้บางส่วน
     b. ตัดสินใจ action ตาม "แผนการรบ" (ดู §6)
     c. ตรวจลมปราณ (MP) พอร่ายวิชาที่เลือกไหม → ไม่พอ fallback โจมตีปกติ
     d. คำนวณ hit/miss → crit → damage → เอฟเฟกต์เสริม (ดูด/สถานะ)
     e. เขียน log บรรทัดผลลัพธ์
     f. ตรวจการตาย → ถ้าเป้าตาย ออกจากคิว
  4. ประมวลผล "สถานะต่อเนื่อง" ปลายรอบ (พิษ/เลือดไหล/ฟื้นฟู) ตามลำดับ SPD
  5. ลดตัวนับ cooldown/duration ของบัฟ-ดีบัฟทุกตัว
  6. ตรวจเงื่อนไขจบการต่อสู้ (ฝ่ายใดเลือดหมดทั้งหมด / หนี / ครบรอบสูงสุด)
```
- **รอบสูงสุด:** 30 รอบ ถ้าไม่จบให้ตัดสินด้วย %เลือดคงเหลือรวม (กันการต่อสู้ค้างนิรันดร์)

## 3. ค่าสถานะหลัก & สูตร (ฉบับเต็ม)
> ⚠️ **โมเดลค่าพื้นฐาน canonical = 7 ค่าแบบ JY (docs/15)** — สูตร derived ที่เป็นทางการอยู่ที่
> docs/15 §2. ด้านล่างเป็นรูปแบบเดิม (STR/INT/AGI/FOC) ที่ **แมปเป็น 7 ค่า** ดังนี้:
> STR→กำลังแขน · INT→ความกล้า(+กระดูกให้ MP) · AGI→ปฏิภาณ · FOC→กระจาย กระดูก/ความกล้า/ฟื้นฟู
```python
# รูปแบบ canonical (7 ค่า, docs/15 §2):
HP   = 50 + กระดูก*12 + ฟื้นฟู*3
MP   = 30 + กระดูก*4 + ความกล้า*7        # ลมปราณ (พลังภายใน)
ATK  = กำลังแขน*2.5 (ภายนอก) | ความกล้า*2+กระดูก*0.5 (ภายใน) + weapon
DEF  = กระดูก*1.2 + ฟื้นฟู*0.3 + armor
ACC  = ปฏิภาณ*1.5    ;  EVA = ปฏิภาณ*1.2
SPD  = ปฏิภาณ*2 + ความกล้า*0.3            # ฝีเท้า (จังหวะ ATB)
CRIT = 0.05 + ความกล้า*0.0015 + วาสนา*0.001   # เพดาน 0.50
CRIT_DMG = 1.5
```
> สูตรดาเมจ/hit/crit §4 ใช้ค่า ATK/DEF/ACC/EVA/SPD/CRIT (derived) ได้เหมือนเดิม —
> เปลี่ยนแค่ที่มาของค่าเป็น 7 ค่าแบบ JY; `weapon_atk/armor_def` จากอุปกรณ์ (docs/05)

### 3.1 ตารางค่าสถานะตามช่วงการเติบโต (ไร้อุปกรณ์)
| ช่วง | STR/INT/AGI/FOC | HP | MP | ATK | DEF | SPD | CRIT |
|---|---|---|---|---|---|---|---|
| เริ่มเกม | 5/5/5/5 | 125 | 90 | 15 | 10 | 12.5 | 6% |
| ต้น | 15/15/15/15 | 275 | 210 | 45 | 30 | 37.5 | 8% |
| กลาง | 40/40/40/40 | 650 | 510 | 120 | 80 | 100 | 13% |
| ปลาย | 70/70/70/70 | 1,100 | 870 | 210 | 140 | 175 | 19% |
| เกือบสุด | 95/95/95/95 | 1,475 | 1,170 | 285 | 190 | 237.5 | 24% |

> ตัวเลขนี้คือ "ฐานเปล่า" — อุปกรณ์ระดับปลายเกม + passive 内功 จะดัน HP จริงไปแตะ
> หลักหลายพัน และ ATK หลักหลายร้อย ตามที่ออกแบบไว้ใน GDD หลัก

## 4. สูตรการคำนวณการปะทะ (Combat Math)
```python
# ---------- 4.1 โอกาสตีเข้า/พลาด ----------
hit_chance = clamp(0.75 + (ACC_atk - EVA_def) * 0.01, 0.10, 0.98)

# ---------- 4.2 คริติคอล ----------
is_crit   = roll() <= clamp(CRIT_atk - CRIT_RES_def, 0.05, 0.50)   # บาง passive ให้ต้านคริติคอล
crit_mult = CRIT_DMG_atk if is_crit else 1.0

# ---------- 4.3 ตัวคูณวิชาตามระดับ ----------
skill_mult = skill_base_mult + skill_level * 0.01      # level 1..100

# ---------- 4.4 ดาเมจ ----------
# ใช้ลดป้องกันแบบ "ลบครึ่ง" เพื่อให้ DEF มีค่าแต่ไม่ตัน (ไม่มี 0 dmg ถาวร)
raw    = (ATK_atk * skill_mult) - (DEF_def * 0.5)
elem   = element_modifier(skill_element, target)        # ธาตุ/คุณสมบัติ (ดู §5)
var    = uniform(0.90, 1.10)
damage = max(1, round(raw * crit_mult * elem * var))

# ---------- 4.5 ดูดเลือด/ดูดภายใน ----------
hp_steal = round(damage * skill.lifesteal_pct)          # คืน HP ผู้ตี
mp_steal = round(damage * skill.mpsteal_pct)            # ดูด MP เป้าหมาย

# ---------- 4.6 ติดสถานะ ----------
land_chance = clamp(skill.status_chance + (ACC_atk - EVA_def)*0.003 - target.status_res, 0.05, 0.95)
if roll() <= land_chance:
    apply_status(target, skill.status, duration=skill.status_dur, power=derive_from(INT_atk))
```

### 4.7 ตัวอย่างการคำนวณ 2 ตา (worked examples)
**ตาที่ 1 — กระบี่ใส่ทรหด (เป้าป้องกันสูง)**
```
ผู้ตี: ATK=210, CRIT=19%, CRIT_DMG=1.6 | วิชา: base_mult=1.4, Lv60 → skill_mult=2.0
เป้า: DEF=140, EVA=60 ; ผู้ตี ACC=175
hit = clamp(0.75 + (175-60)*0.01,..,0.98)=0.98  → roll 0.31 เข้า
crit: roll 0.55 > 0.19 → ไม่คริติคอล (mult=1.0)
raw = 210*2.0 - 140*0.5 = 420 - 70 = 350
var=0.96 → damage = round(350*1.0*1.0*0.96)=336
```
**ตาที่ 2 — วิชาพิษติดสถานะ**
```
ผู้ตี(หุบเขายาพิษ): ATK=120, INT=80 ; วิชา base_mult=0.9 Lv80 → skill_mult=1.7
                    status_chance=0.45, สถานะ=พิษ
เป้า: DEF=80, status_res=0.10 ; ผู้ตี ACC=150, เป้า EVA=40
raw = 120*1.7 - 80*0.5 = 204-40 = 164 ; var=1.04 → damage=171
land = clamp(0.45 + (150-40)*0.003 - 0.10,..)=0.68 → roll 0.5 ติดพิษ!
พิษ: ดาเมจต่อรอบ = round(INT*0.5 * (1+ระดับ*0.005)) = round(40*0.5*(1+0.4))=28 ต่อรอบ 4 รอบ  # Lv80
```

## 5. ระบบธาตุ/คุณสมบัติวิชา (Element / Affinity)
JY-style: วิชาแบ่งตาม "สาย" ที่มีความสัมพันธ์เด่น-ด้อยเล็กน้อย (ไม่รุนแรงจน rock-paper-scissors)
| สายวิชา | เด่นต่อ | ด้อยต่อ | ลักษณะ |
|---|---|---|---|
| กระบี่/ดาบ (คม) | เกราะหนัง | เกราะเหล็ก | ดาเมจตรง คริติคอลดี |
| ฝ่ามือ/หมัด (ปะทะ) | เกราะเหล็ก | ตัวเบา | ทะลุป้องกัน |
| พิษ/มาร (เจตนา) | เลือดมาก | จิตสูง(FOC) | DoT/ดีบัฟ |
| ลมปราณบริสุทธิ์ | มาร | กายภาพ | ฟื้นฟู/ลบสถานะ |
```python
def element_modifier(elem, target):
    if strong_against(elem, target.armor_type): return 1.15
    if weak_against(elem, target.armor_type):   return 0.90
    return 1.0
```
> **เหตุผล:** ±10–15% พอให้การ "อ่านคู่ต่อสู้แล้วจัดวิชา" มีความหมาย แต่ไม่ทำให้ผู้เล่น
> ที่บิลด์ผิดธาตุแพ้ขาด — สกิลการจัดทีม/ค่าพลังยังเป็นตัวหลัก

**ค่าโจมตีพิเศษธาตุจากอุปกรณ์ (Elemental Imprint):** อาวุธ/ยุทโธปกรณ์ที่คราฟต์โดยช่างสายธาตุ
(ตะวัน/ดารา/จันทรา — docs/14 §5.2) มีค่า `elem_power` เพิ่มดาเมจธาตุต่อครั้ง + proc เฉพาะธาตุ:
```python
elem_bonus = elem_power * element_modifier(weapon_element, target)   # บวกหลังดาเมจปกติ
total_damage = damage + elem_bonus
if roll() <= elem_proc_chance: apply_element_effect(target, weapon_element)  # เผา/เจาะ/ดูด-ดีบัฟ
```

## 6. แผนการรบ (Battle Tactics / AI Script)
ผู้เล่นตั้งค่า "สคริปต์" ก่อนรบ — ประมวลจากบนลงล่าง ใช้เงื่อนไขแรกที่เป็นจริง
```
ตัวอย่างสคริปต์ผู้เล่น:
  1) IF เลือดตัวเอง < 30%       THEN ใช้ "ยาเลือดใหญ่"
  2) IF เพื่อนร่วมทีม < 40%      THEN ร่าย "ธาราคืนชีพ"
  3) IF ลมปราณ >= 18 AND เป้าไม่ติดพิษ THEN ร่าย "หมอกพิษเจ็ดสี"
  4) IF มีเป้าเลือด < 25%        THEN ร่าย "ท่าไม้ตายสังหาร"
  5) ELSE                        โจมตีปกติ เป้าที่ EVA ต่ำสุด
```
- **เป้าหมายอัตโนมัติ (targeting):** เลือกได้ — ศัตรูเลือดน้อยสุด / ป้องกันต่ำสุด / สุ่ม / โฟกัสตัวที่ทีมตี
- จำนวนบรรทัดสคริปต์ปลดเพิ่มได้ตามชื่อเสียง (เริ่ม 5 บรรทัด → สูงสุด 10)
> **เหตุผล:** ให้ความลึกเชิงกลยุทธ์แบบ "เขียน AI ตัวเอง" โดยไม่ต้องกดเรียลไทม์ —
> เป็นเอกลักษณ์ที่ทำให้ผู้เล่นเก่งต่างจากผู้เล่นทั่วไปแม้ค่าพลังใกล้กัน

## 7. ระบบสถานะผิดปกติ (Status Effects)
| สถานะ | ผล | ระยะ | กลไกถอน |
|---|---|---|---|
| **พิษ** (Poison) | เสียเลือดต่อรอบ = f(INT ผู้ร่าย), ซ้อนได้สูงสุด 5 ชั้น | 3–5 รอบ | ยาถอนพิษ / วิชาล้างพิษ |
| **เลือดไหล** (Bleed) | เสียเลือดต่อรอบ = %max HP เป้า | 2–4 รอบ | ฟื้นเลือด/หมดเวลา |
| **มึน** (Stun) | ข้ามตา 1 รอบ ออกท่าไม่ได้ | 1 รอบ | หมดเวลา / วิชาปลุก |
| **ตรึง** (Root) | ออกท่าได้แต่ SPD=0 (ออกท้ายคิว) + หลบไม่ได้ | 1–2 รอบ | หมดเวลา / วิชาตัวเบา |
| **สับสน** (Confuse) | มีโอกาสตีพวกเดียวกัน/ตีพลาด | 1–2 รอบ | หมดเวลา |
| **ปิดลมปราณ** (Seal) | ร่ายวิชา active ไม่ได้ ใช้ได้แต่โจมตีปกติ | 2 รอบ | ยาพิเศษ/หมดเวลา |
| **อ่อนเปลี้ย** (Weaken) | ATK -25% | 2–3 รอบ | หมดเวลา |
| **เปิดจุด** (Vulnerable) | รับดาเมจ +20% | 2 รอบ | หมดเวลา |

**กลไกต้านทาน (Status Resist):**
```python
target.status_res = base_res + FOC*0.003 + passive_bonus    # FOC สูง = ทนสถานะ
# ทุกครั้งที่ติดสถานะเดิมซ้ำ res ชั่วคราว +0.05 (กัน perma-lock / diminishing returns)
```
> **เหตุผล:** DR ของการติดสถานะกัน "ล็อกตาย" ใน PvP — Controller ยังมีค่าแต่ไม่ทำให้
> เป้าหมายเล่นไม่ได้ทั้งแมตช์

## 8. การหนี, การจับ, และผลแพ้ (Flee / Capture / Defeat)

## 9. การฟื้นฟูนอกการต่อสู้ (Out-of-Combat Recovery) — สไตล์ JY
- **นั่งสมาธิ (运功/Meditate):** ฟื้น HP/MP ต่อวินาทีตามค่า INT/FOC; ขยับ/ถูกตีจะหลุดสมาธิ
```
hp_regen_per_tick = 2 + FOC*0.1      # ต่อ tick (เช่นทุก 3 วินาที)
mp_regen_per_tick = 2 + INT*0.15
```
- **ยา & อาหาร:** ฟื้นทันที มี cooldown ป้องกันสแปม
- กลไกนี้ทำให้ FOC/INT มีคุณค่านอกเหนือดาเมจ และสนับสนุนจังหวะ "ฟาร์ม-พัก-ฟาร์ม"
