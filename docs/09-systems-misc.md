# 09 — ระบบเสริมสไตล์ JY Online (Supporting Systems)

> ระบบรอบนอกที่ทำให้โลกกำลังภายในมีชีวิตและช่วย retention — อ้างอิง JY Online
> ทุกระบบเชื่อมกลับเข้า core loop (ต่อสู้→EXP→ฝึกวิชา→ชื่อเสียง)

---

## 1. นั่งสมาธิ / เดินลมปราณ (运功 / Meditate)
- ฟื้น HP/MP นอกการต่อสู้; ในเมืองปลอดภัยสะสม **rested bonus** (docs/03 §5)
- random event หายากระหว่างสมาธิ: "พบแจ้งในธรรม" +1 COM (แหล่ง COM นอกเนื้อเรื่อง)
- "เดินลมปราณฝ่าด่าน" ของ 内功 ขั้นสูง: ภารกิจย่อยฝึกพลังภายในปลดเพดานบางวิชา

## 2. พาหนะ & การเดินทาง (Mounts / Travel)
- **ม้า/พาหนะ:** เพิ่มความเร็วเดินทางบนแผนที่โลก (ไม่ใช่ค่ารบ), มีระดับ/ของตกแต่ง
- **เดินทางด่วน (传送):** ระหว่างเมืองที่ปลดแล้ว เสียเงิน (gold sink)
- พาหนะหายาก = prestige + ของสะสม (ไม่ให้พลังรบ → กัน pay/grind-to-win)

## 3. ระบบอาจารย์–ศิษย์ (师徒) — ดู docs/06 §7
- สรุปกลไกเสริม retention: ผูกผู้เล่นเก่า-ใหม่, ให้รางวัลร่วมเมื่อศิษย์เติบโต/สำเร็จภารกิจ

## 4. ระบบที่อยู่อาศัย / สวนยา (Housing / Herb Garden) — optional Phase 3
- บ้านส่วนตัว/ลานสำนัก: ปลูกสมุนไพร (วัตถุดิบหมอยา), เลี้ยงสัตว์, ตั้งเตาคราฟต์
- เป็น **เศรษฐกิจฐานราก** ป้อนวัตถุดิบเข้าตลาด + sink (ค่าดูแล/อัปเกรด)
- gameplay เนิบช้าสำหรับผู้เล่นสายสร้าง/ค้าขาย เพิ่มความหลากหลายผู้เล่น

## 5. ระบบสัตว์เลี้ยง/อสุรกาย (Companion) — optional
- สัตว์คู่ใจช่วยรบ (สถานะแยก, โตด้วยการใช้งาน), เติมบทบาทที่ทีมขาด
- ออกแบบให้เป็น "เสริม" ไม่เกินผู้เล่น เพื่อไม่ลดคุณค่าการจัดปาร์ตี้จริง

## 6. ปฏิทินอีเวนต์ & ฤดูกาล (Events / Seasons)
| อีเวนต์ | ความถี่ | ผล |
|---|---|---|
| เทศกาลยุทธภพ | ตามเทศกาลไทย/จีน | เควสพิเศษ, ของตกแต่ง, +find_rate |
| บอสโลกอุบัติ | สุ่ม/สัปดาห์ | รวมพลทั้งเซิร์ฟ |
| ซีซันจัดอันดับ | ราย 1–3 เดือน | รีเซ็ตลีก, รางวัลซีซัน, ฉายา |
| ศึกชิงเมืองใหญ่ | รายสัปดาห์ | สงครามสำนัก (docs/06 §5) |
> ซีซันรีเซ็ตอันดับ (ไม่รีเซ็ตตัวละคร) ให้ผู้เล่นใหม่มีโอกาสไต่อันดับ → retention วงกว้าง

## 7. UX สำหรับ text-based (สำคัญต่อความเล่นได้)
- **Combat log อ่านง่าย:** สี/ไอคอนแยกประเภท (ดาเมจ/คริติคอล/ฟื้น/สถานะ/พลาด), ปุ่มเร่ง/ข้าม
- **สรุปหลังรบ:** EXP ที่ได้ (+เพดานเหลือ), drop, prof วิชาที่ขึ้น
- **แผง "ผังวิชา" 3 ชุด:** สลับ PvE/PvP/บอสได้เร็ว (docs/02 §5)
- **ตัวช่วยสคริปต์รบ:** เทมเพลตสำเร็จรูปสำหรับมือใหม่ + ปรับเองสำหรับมือเก๋า
- **มือถือ-first:** ปุ่มใหญ่, โหลดเบา, เล่นแนวตั้งได้, รองรับเน็ตช้า/หลุดแล้วต่อ

## 8. ระบบกันโกง/สมดุลเซิร์ฟ (Integrity)
- ประมวลผลการรบ/EXP/drop ฝั่ง **server-authoritative** ทั้งหมด (client แสดงผลอย่างเดียว)
- rate-limit การฟาร์ม, ตรวจ pattern บอท, log การไหลของเงิน/ของเพื่อ monitor เงินเฟ้อ
- การฝึกวิชา/อัปค่าตรวจสอบเงื่อนไข (COM/EXP/ชื่อเสียง) ฝั่งเซิร์ฟทุกครั้ง

---

## ภาคผนวก — สรุปการเชื่อมโยงทุกระบบเข้า Core Loop
```
            ┌─────────────────────── ต่อสู้ (PvE/บอส/PvP) ───────────────────────┐
            │                                                                    │
   Combat EXP + drop + เงิน + ชื่อเสียง + prof วิชา                                │
            │                                                                    │
   ┌────────┼─────────┬──────────────┬───────────────┐                          │
   ▼        ▼         ▼              ▼               ▼                           │
ฝึกวิชา  อัปค่าพื้นฐาน  คราฟต์/ตีบวก   ทำเควสชื่อเสียง   เข้าสังคม/สำนัก                  │
(↑ระดับ) (↑attr)     (↑อุปกรณ์)     (↑เพดาน/ปลดวิชา)  (อาจารย์-ศิษย์/สงคราม)         │
   │        │         │              │               │                           │
   └────────┴─────────┴──────────────┴───────────────┘                          │
            │  ↑ PI สูงขึ้น (แกร่งขึ้น)                                            │
            └──────────► ท้าทายศัตรู/ดินแดน/ผู้เล่นที่ยากขึ้น ──────────────────────┘
```
> ทุกกล่องป้อนกลับเข้าการต่อสู้ และการต่อสู้ป้อนทุกกล่อง — ไม่มีระบบลอยเดี่ยว
