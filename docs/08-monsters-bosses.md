## 3. ดีไซน์บอส (Boss Design) — กลไกหลายเฟส
บอสภูมิภาค/โลกออกแบบเป็น **เฟส** ตาม %HP เพื่อต้องการการจัดทีม (tank/heal/dps/controller):
```
ตัวอย่าง: ปีศาจดาวร่วง (บอสโลก, PI 2,400)
 เฟส 1 (100–70% HP): โจมตีเดี่ยวแรง + เรียกบริวาร (controller จัดการบริวาร)
 เฟส 2 (70–35%):     AoE พิษทั้งสนามทุก 3 รอบ (healer/ถอนพิษสำคัญ; tank ยืนรับ)
 เฟส 3 (35–0%):      "ปลดผนึกดาวร่วง" +50% ATK, ออกท่าไม้ตายเปิดจุดทั้งทีม
                     (ต้องเบิร์สต์ปิดเกม/มี cooldown ลดดาเมจ)
 Enrage: เกิน 30 รอบ → ดาเมจบอส x3 (กันตีค้าง/ฟาร์มเกินตั้งใจ)
```
**Contribution & EXP บอสโลก:**
```python
share = my_damage_and_support / total_party_contribution
my_world_boss_exp = boss_base_exp * clamp(share, 0.02, 0.4)   # cap กันโขกคนเดียว
# healer/tank นับ support score (heal/รับดาเมจ/เย้ย) เพื่อไม่ถูกตัดสิทธิ์รางวัล
```
> **เหตุผล:** เฟสบังคับความหลากหลายบทบาท → ทุกสำนักมีที่ยืน; contribution แบบนับ support
> ทำให้ healer/tank ได้รางวัลคุ้ม ไม่ใช่แค่ DPS

## 4. ดันเจี้ยน & คอนเทนต์วนซ้ำ (Repeatable Content)
| คอนเทนต์ | รอบ | รางวัล |
|---|---|---|
| ดันเจี้ยนสำนัก (3–5 คน) | รายวัน | ตำรา, วัตถุดิบคราฟต์, EXP |
| หอคอยพิชิต (ชั้นไต่ขึ้น) | รีเซ็ตรายสัปดาห์ | ของฝึก, หยก, ฉายาตามชั้นสูงสุด |
| บอสภูมิภาค | cooldown รายวัน | ตำราขั้นสูง, ม่วง |
| บอสโลก | สัปดาห์/อีเวนต์ | ส้ม, เศษคัมภีร์, COM |
| ภารกิจล่าค่าหัว PvE | สุ่มหมุนเวียน | เงิน, ของหายาก |
> หอคอยพิชิตใช้ PI scaling — ชั้นสูงขึ้น PI ศัตรูสูงขึ้น เป็น "ไม้บรรทัด" วัดความแกร่งตัวเอง

## 5. AI ศัตรู (Enemy Behavior)
- ใช้สคริปต์แบบเดียวกับผู้เล่น (docs/01 §6) — บอสมีสคริปต์ซับซ้อนหลายเงื่อนไข/เฟส
- พฤติกรรม targeting: บางบอสโฟกัส healer (บีบให้มี tank/peel), บางตัวสุ่ม
- โทรเลขท่าใหญ่ (telegraph): ก่อนออกท่าไม้ตาย log จะเตือน 1 รอบ → ผู้เล่นมีโอกาสตั้งรับ
  (เดินหลบเขตเตือนบนกริด/ใช้วิชาลดดาเมจ/เกราะ/ฟื้น) — สร้าง counter-play เชิงตำแหน่ง real-time (docs/11 §9)

## 6. ระบบ drop (Loot Tables)
```python
for entry in loot_table:
    if roll() <= entry.chance * find_rate_bonus:   # find_rate จาก buff/ฉายา/อีเวนต์
        drop(entry.item, qty=entry.qty)
# ของหายาก (ตำราสุดยอด/ส้ม) ใช้ระบบ "pity": ตีบอสครบ N ครั้งไม่ออก → การันตี
```
> pity counter กันดวงซวยยาว → ลดความหงุดหงิด รักษา retention ของสาย PvE
