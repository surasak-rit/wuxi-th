## 1. ระดับคุณภาพไอเทม (Rarity)
| ระดับ | สี | แหล่ง | ช่องเสริม (slot) |
|---|---|---|---|
| สามัญ (ขาว) | ⚪ | ร้าน/มอนทั่วไป | 0 |
| ดี (เขียว) | 🟢 | มอน elite/คราฟต์ | 0–1 |
| เลิศ (น้ำเงิน) | 🔵 | บอสภูมิภาค/คราฟต์ขั้นสูง | 1–2 |
| หายาก (ม่วง) | 🟣 | บอสโลก/ดันเจี้ยน | 2–3 |
| ตำนาน (ส้ม) | 🟠 | บอสโลก/เนื้อเรื่อง/ตีบวกสุด | 3 + คุณสมบัติพิเศษ |

## 2. ประเภทไอเทม & ผลต่อค่าสถานะ
| ประเภท | ช่องสวม | ผลหลัก |
|---|---|---|
| อาวุธ (กระบี่/ดาบ/กระบอง/ฝ่ามือ-สนับ/มีดสั้น) | 1 | `weapon_atk`, อาจ +CRIT/+ธาตุ |
| เสื้อเกราะ | 1 | `armor_def`, +HP |
| หมวก/ผ้าโพก | 1 | +DEF, +ต้านสถานะ |
| รองเท้า | 1 | +SPD, +EVA |
| เครื่องประดับ (หยก/แหวน) | 2 | +ค่าพื้นฐาน, +MP |
| เครื่องราง (เซียน) | 1 | คุณสมบัติพิเศษ (เช่น เริ่มรบมีเกราะ) |

**Gear Score (ใช้ใน PI):**
```python
gear_score = sum(item.ilvl * rarity_mult for item in equipped) + enhance_bonus
rarity_mult = {ขาว:1, เขียว:1.3, น้ำเงิน:1.7, ม่วง:2.2, ส้ม:3.0}
```

## 3. ระบบช่องเสริม & หยกสลัก (Sockets / Gems)
- ใส่ "หยกธาตุ" ในช่อง: เพิ่มค่าพื้นฐาน/ต้านทาน/ดูดเลือด ฯลฯ
- หยกอัปเกรดได้ (รวม 3 เม็ดเล็ก → 1 เม็ดใหญ่) = sink วัตถุดิบ
- ถอดหยกเสียค่าธรรมเนียม (sink)

## 4. คราฟต์ (Crafting)
- อาชีพคราฟต์: **ช่างตีเหล็ก** (อาวุธ/เกราะ), **หมอยา** (ยา/ยาพิษ), **นักเล่นแร่** (หยก/วัตถุดิบ)
- สูตร = วัตถุดิบ + พิมพ์เขียว (drop/ซื้อ) + ค่าแรง (เงิน = sink)
```python
craft_quality = base + skill_level*0.5 + luck_roll      # สุ่มคุณภาพผลลัพธ์
# คุณภาพสูง → จำนวน slot/ค่าพื้นฐานติดของมากขึ้น (จูงใจคราฟต์ซ้ำเพื่อของดี)
```

## 6. ยา & ของใช้สิ้นเปลือง
| ไอเทม | ผล | cooldown |
|---|---|---|
| ยาเลือด (เล็ก/กลาง/ใหญ่) | ฟื้น HP ทันที | 3 รอบ |
| ยาลมปราณ | ฟื้น MP | 3 รอบ |
| ยาถอนพิษ | ล้างพิษ/สถานะ | 2 รอบ |
| ยาเพิ่มพลังชั่วคราว | +ATK/+SPD ช่วงเวลา | นอกรบ |
| อาหารบำรุง | +rested rate / +EXP เล็กน้อย | buff หมดอายุ |
> ยามี cooldown ในรบ → กันการ "จิบยาไม่ตาย" และให้ healer มีคุณค่า

## 7. เงินตรา & ตลาดผู้เล่น
- สกุล: ทองแดง → เงิน (×100) → ทอง (×100)
- **ตลาดประมูล (AH):** ลงขายเก็บค่ามัดจำ + ค่าธรรมเนียมขายสำเร็จ 5% (sink)
- **แผงเร่ผู้เล่น:** ตั้งร้านในเมือง ขายตรง เก็บค่าเช่าแผงรายชั่วโมง (sink)
- **ผูกบัญชี (bind):** ของจากเนื้อเรื่อง/รางวัล bind ป้องกันการเทขายทำลายตลาด
