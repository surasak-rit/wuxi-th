# 14 — ระบบอาชีพ / ชีพวิถี (Profession & Crafting Chain)

> สายโซ่ **เก็บเกี่ยววัตถุดิบ → แปรรูปขั้นต้น → ผลิตสินค้า** ที่ขับเคลื่อนเศรษฐกิจผู้เล่น
> ป้อนเข้า: ไอเทม/ตีบวก/หยก (docs/05), ของใช้ฝึกปรือ (ธูป/อาหาร docs/13), เครื่องราง/ตำรา
> หลักการ: **ไม่มีใครทำได้ครบทุกอย่าง** → เกิดการพึ่งพา/ค้าขายระหว่างผู้เล่น

## 1. ภาพรวมสายโซ่ (Production Chain)
```
[โลก/โหนด]   เก็บเกี่ยว        วัตถุดิบดิบ      แปรรูปขั้นต้น       ช่างผลิต           สินค้าใช้งาน
─────────────────────────────────────────────────────────────────────────────────────────
เหมืองแร่   ─► แร่ดิบ        ─► ถลุง → แท่งโลหะ ─► ช่างอาวุธ/เกราะ  ─► อาวุธ / เกราะโลหะ
            └► หยกดิบ        ─► เจียระไน → หยก  ─► ช่างหยก          ─► หยกสลัก (socket)
เก็บสมุนไพร  ─► สมุนไพร       ─► สกัด → สารสกัด   ─► เภสัช (หมอยา)    ─► ยา / ยาพิษ / ธูปสมาธิ
ล่า/ชำแหละ   ─► หนัง/เอ็น     ─► ฟอก → หนังฟอก   ─► ช่างหนัง         ─► เกราะหนัง / รองเท้า
ตัดไม้      ─► ไม้ดิบ        ─► เลื่อย/อบ → ไม้   ─► ช่างไม้          ─► ด้ามอาวุธ/ธนู/เครื่องราง
ตกปลา/เก็บ  ─► ปลา/ของน้ำ    ─► (สด)            ─► ปรุงอาหาร        ─► อาหารบัฟ (rested/บัฟ)
ปลูก/ทอ     ─► ฝ้าย/ใยไหม    ─► ทอ → ผ้า         ─► ช่างผ้า/จารตำรา   ─► เสื้อใน/ตำราเปล่า
```
> สินค้าปลายทางไปต่อที่ **ตีบวก/สลักหยก (docs/05 §3,5)** และ **ตลาดผู้เล่น (docs/05 §7)**

## 2. ช่องอาชีพ & กติกา (Profession Slots)
- **อาชีพหลัก: เลือกได้ 2 ช่อง** จากทั้งกลุ่มเก็บเกี่ยว + กลุ่มแปรรูป (ผสมได้ตามใจ)
  - เช่น "เหมืองแร่ + ช่างอาวุธ" (สายพึ่งตัวเอง) หรือ "เก็บสมุนไพร + เก็บแร่" (สายป้อนตลาด)
- **อาชีพชีวิต (รอง): ตกปลา & ปรุงอาหาร** — ทุกคนทำได้ ไม่กินช่อง (กิจกรรมเบาๆ/สังคม)
- เปลี่ยนอาชีพหลักได้ แต่ **รีเซ็ตระดับอาชีพนั้น + เสียค่าธรรมเนียม** (กันสลับมั่ว = sink)

### 2.1 เพดานความเชี่ยวชาญต่อตัวละคร (Mastery Cap) — กันคนเดียวสุดทุกสาย
แม้จะมี 2 ช่อง แต่ **ไม่ให้ทั้งสองช่องไปถึงปรมาจารย์พร้อมกัน** — ใช้ระบบ **สายเอก/สายรอง**:
| บทบาท | เพดานระดับ | ได้เกรดสูงสุด |
|---|---|---|
| **สายเอก (Primary)** — เลือก 1 อาชีพ | **Lv100 (ปรมาจารย์)** | ตำนาน (ส้ม) + สูตรลับ + ตีตราช่าง |
| **สายรอง (Secondary)** — อีก 1 ช่อง | **Lv60 (ชั้นครู)** | เลิศ (น้ำเงิน) |
| อาชีพชีวิต (ตกปลา/ทำอาหาร) | Lv50 | บัฟระดับกลาง |
- **เลือกสายเอกได้ 1 เท่านั้น/ตัวละคร** → ตัวละครหนึ่งเป็น "ปรมาจารย์" ได้แค่ **1 อาชีพ**
- (เสริม) **งบความเชี่ยวชาญรวม (Mastery Budget) = 160** = ผลรวมระดับอาชีพหลักทั้งหมด
  (เช่น 100+60) — ฝึกเกินงบไม่ได้ คุมเพดานรวมอีกชั้น
- **สลับสายเอก↔สายรองได้** (ค่าธรรมเนียม + cooldown): ระดับของอาชีพที่ "ตกเป็นสายรอง" จะถูก
  **ล็อกใช้งานแค่ถึง Lv60** (ระดับส่วนเกินถูกพักไว้ ไม่ลบ แต่จะกลับมาใช้ได้ก็ต่อเมื่อสลับเป็นสายเอกอีกครั้ง)
  → ขณะใดขณะหนึ่ง **มีอาชีพระดับปรมาจารย์ที่ใช้งานได้เพียง 1**
> **เหตุผล:** 2 ช่อง + สายเอก/สายรอง → ตัวละครเป็น "ปรมาจารย์ได้สายเดียว, เก่งรองอีกสาย" →
> ปรมาจารย์แต่ละสายหายากจริง มีค่าตลาด/ชื่อเสียงช่าง และผู้เล่นต้องพึ่งพา/ค้าขายกัน
> (ไม่มีตัวละครเดียวผลิตของท็อปได้ครบทุกหมวด) = เศรษฐกิจคึกคัก + retention เชิงสังคม

## 3. กลุ่มอาชีพเก็บเกี่ยว (Gathering)
| อาชีพ | เก็บจาก (โหนด) | ผลผลิต | เครื่องมือ |
|---|---|---|---|
| เหมืองแร่ (Mining) | สายแร่ในถ้ำ/ภูเขา | แร่เหล็ก/เงิน/ทอง/หยกดิบ | พลั่ว/สิว (มี durability) |
| เก็บสมุนไพร (Herbalism) | กอสมุนไพรในป่า/หุบเขา | สมุนไพรหลายชนิด | เคียว |
| ล่า/ชำแหละ (Skinning) | ซากสัตว์ที่ล่าได้ (ผูกการต่อสู้) | หนัง/เอ็น/กระดูก | มีดชำแหละ |
| ตัดไม้ (Logging) | ต้นไม้ในป่า | ไม้ดิบหลายเกรด | ขวาน |
| ตกปลา (Fishing) | จุดตกปลา/แม่น้ำ-ทะเล | ปลา/สาหร่าย/ไข่มุก (rare) | คันเบ็ด |

**กลไกเก็บเกี่ยว:**
- โหนดมี **เทียร์ตามโซน** — โซน PI สูง/อันตราย = วัตถุดิบเกรดสูง (ผูกการสำรวจ/ต่อสู้)
- ใช้เวลาเก็บต่อโหนด + เครื่องมือสึก (durability = sink ค่าซ่อม) + โหนด respawn
- โอกาสได้ของหายาก (rare drop) ระหว่างเก็บ → ตื่นเต้น + ป้อนของแพงเข้าตลาด

## 4. กลุ่มอาชีพแปรรูป/ผลิต (Processing & Crafting)
| อาชีพ | สถานี (station) | รับวัตถุดิบ | ผลิต |
|---|---|---|---|
| ถลุงโลหะ (Smelting) | เตาหลอม | แร่ดิบ → แท่งโลหะ | แท่งเหล็ก/เงิน/ทอง |
| ช่างอาวุธ (Weaponsmith) | เตา/ทั่ง | แท่งโลหะ + ด้ามไม้ | อาวุธ (กระบี่/ดาบ/กระบอง/มีด) |
| ช่างเกราะ (Armorsmith) | ทั่ง | แท่งโลหะ | เกราะโลหะ/หมวก |
| ช่างหนัง (Leatherworking) | โต๊ะฟอก | หนังฟอก + เอ็น | เกราะหนัง/รองเท้า |
| ช่างไม้ (Woodworking) | โต๊ะช่างไม้ | ไม้แปรรูป | ด้ามอาวุธ/ธนู/เครื่องราง/เฟอร์นิเจอร์บ้าน |
| ช่างหยก (Jeweler) | โต๊ะเจียระไน | หยกดิบ | หยกสลัก (socket gem, docs/05 §3) |
| เภสัช/หมอยา (Alchemy) | เตายา | สารสกัดสมุนไพร | ยาเลือด/ลมปราณ/ถอนพิษ, ยาพิษ, **ธูปสมาธิ** (docs/13 §7) |
| ปรุงอาหาร (Cooking) | เตาครัว | ปลา/วัตถุดิบ | **อาหารบัฟ** (+rested/+อัตราฝึก) |
| จารตำรา (Inscription) | โต๊ะจาร | ผ้า/หมึก | ตำราเปล่า/ม้วนเสริม, ป้ายฉายา |

**กลไกแปรรูป:**
- สูตร (recipe) = วัตถุดิบ + สถานี + **ระดับอาชีพขั้นต่ำ** + เวลา/ค่าแรง (เงิน = sink)
- คุณภาพผลลัพธ์สุ่มตามสูตร docs/05 §4: `craft_quality = base + prof_level*0.5 + luck`
- พิมพ์เขียว/สูตรหายาก (drop/ซื้อ/รางวัลอาชีพ) ปลดของระดับสูง

## 5. ระดับอาชีพ & เทียร์ (Profession Level 1–100)
ทำอาชีพ (เก็บ/แปรรูป) สำเร็จ → ได้ **prof-XP** เลื่อนระดับ; ปลดโหนด/สูตรเกรดสูงขึ้น
| เทียร์ | ช่วงระดับ | ปลดล็อก |
|---|---|---|
| ฝึกหัด | 1–20 | วัตถุดิบ/สูตรพื้นฐาน |
| ชำนาญ | 21–40 | เกรดดี (เขียว) |
| ชั้นครู | 41–60 | เกรดเลิศ (น้ำเงิน) + เพิ่ม slot คราฟต์พร้อมกัน |
| เชี่ยวชาญ | 61–80 | เกรดหายาก (ม่วง) + ลดอัตราล้มเหลว |
| ปรมาจารย์ | 81–100 | เกรดตำนาน (ส้ม) + สูตรลับ + ตีตรา "ผลงานช่าง<ชื่อผู้เล่น>" |
> เทียร์ **เชี่ยวชาญ–ปรมาจารย์ (61–100) เปิดเฉพาะ "สายเอก"** (§2.1); สายรองตันที่ Lv60 (ชั้นครู),
> อาชีพชีวิตตันที่ Lv50 → ของเกรดตำนานผลิตได้โดยปรมาจารย์สายเอกเท่านั้น
```python
prof_xp_gain = base_per_action * (1.0 if node_tier <= prof_tier else 0.3)  # ทำของต่ำกว่ามากได้ XP น้อย
# โอกาสสำเร็จ/คุณภาพคราฟต์เพิ่มตาม prof_level (docs/05 §4)
```
> ตีตรา "ผลงานช่าง" บนของระดับปรมาจารย์ → ชื่อเสียงช่าง = prestige + มูลค่าตลาดสูงขึ้น (retention สายคราฟต์)

## 6. คุณภาพวัตถุดิบ → คุณภาพสินค้า (Quality Flow)
```
เก็บเกี่ยวเกรดสูง (โซนอันตราย/ดวงดี) → วัตถุดิบคุณภาพสูง
   → แปรรูปได้ค่า craft_quality สูงขึ้น → สินค้ามี slot/ค่าพื้นฐานดีกว่า (docs/05 §3-4)
```
- คุณภาพไหลทั้งสาย: ของดิบดี + ช่างเก่ง = สินค้าเทพ → จูงใจทั้งสายเก็บเกี่ยวและแปรรูป
- ของระดับตำนาน (ส้ม) ต้องใช้ทั้งวัตถุดิบหายาก (จากบอส/โซนลึก) + ช่างปรมาจารย์ → endgame เศรษฐกิจ

## 7. การเชื่อมเศรษฐกิจ & sinks (Economy Integration)
| Faucet (อาชีพป้อน) | Sink (อาชีพดูด) |
|---|---|
| วัตถุดิบจากเก็บเกี่ยว | ค่าแรงคราฟต์/ถลุง (เงิน) |
| สินค้าจากแปรรูป (ขายในตลาด) | ค่าซ่อมเครื่องมือ (durability) |
| ของหายากจากโหนด/ดวง | ค่าธรรมเนียมตลาด 5% (docs/05 §7) |
| | ค่าเปลี่ยนอาชีพ/รีเซ็ตระดับ |
| | วัตถุดิบที่ถูกบริโภคในการตีบวก/สลักหยก (docs/05) |
- โซ่อุปทาน: เก็บเกี่ยว(faucet วัตถุดิบ) → แปรรูป(เพิ่มมูลค่า+กินวัตถุดิบ) → ผู้เล่นรบ(บริโภคยา/อาหาร/อาวุธ)
  → ของสึก/ใช้หมด → ซื้อใหม่ → วนเศรษฐกิจ
> สินค้าบริโภค (ยา/อาหาร/ธูป/ผ้ายันต์กันแตก) คือ **demand ถาวร** จากผู้เล่นรบ → อาชีพมีตลาดเสมอ

## 8. การเชื่อมระบบอื่น
- **ของใช้ฝึกปรือ (docs/13):** ธูปสมาธิ(+อัตราฝึก), อาหาร(+rested), เคล็ดทะลวงด่าน(บางส่วนคราฟต์)
- **อุปกรณ์/ตีบวก/หยก (docs/05):** อาวุธ/เกราะ/หยกสลัก ทั้งหมดมาจากอาชีพ
- **บ้าน/สวนยา (docs/09 §4):** ปลูกสมุนไพร/เลี้ยงสัตว์ = ฐานป้อนวัตถุดิบ + ตั้งสถานีคราฟต์
- **สำนักผู้เล่น (docs/06):** เทคสำนักปลดสถานีร่วม/โบนัสอัตราคราฟต์ของสมาชิก
- **คอนเทนต์ต่อสู้:** โหนดเกรดสูงอยู่โซนอันตราย → ต้องแกร่งพอจะไปเก็บ (ผูก core loop)

## 9. เหตุผลเชิงดีไซน์ (สรุป)
- **2 ช่องอาชีพ** บังคับความเชี่ยวชาญ → พึ่งพา/ค้าขาย → เศรษฐกิจผู้เล่นคึกคัก
- **สายโซ่หลายขั้น** (ดิบ→แปรรูป→ผลิต) สร้างชั้นมูลค่า + บทบาทผู้เล่นหลากหลาย (สายเก็บ/สายช่าง/สายค้า)
- **demand บริโภคถาวร** (ยา/อาหาร/ของสึก) ทำให้อาชีพมีรายได้ต่อเนื่อง ไม่ใช่ทำครั้งเดียวจบ
- ทุกขั้นมี **sink** (ค่าแรง/ซ่อม/ธรรมเนียม) คุมเงินเฟ้อ (docs/05 §8)
