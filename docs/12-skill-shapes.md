# 12 — รูปทรงพื้นที่โจมตีของวิชา (Skill AoE Shapes)

> ต่อยอด docs/11 §7 (Radial) และ docs/10 (skill schema) — นิยาม "ทรงพื้นที่" ของวิชาแต่ละท่า
> บนกริด ใช้กำหนด **ช่องที่โดนผล** และ **ระยะการโจมตี** ทุกทรงเป็น data-driven + ขยายตามระดับวิชาได้
>
> สัญลักษณ์แผนภาพ (กริดสี่เหลี่ยม default, มุมมองจากด้านบน): `C`=ตัวละครผู้ร่าย ·
> `#`=ช่องที่โดนผล · `.`=ช่องว่าง · "หน้า" = ทิศที่ผู้เล่นเล็ง (orientation)

---

## 1. หลักการรวม (Shape System)
- วิชาแต่ละท่ามีฟิลด์ `shape` = `{ type, params, orientation, scaling }`
- เอนจินแปลง shape → **รายการ offset ช่อง** (เทียบจากตัวละคร) แล้ว:
  1. หมุนตาม `orientation` (สำหรับทรงมีทิศ) → ได้ช่องจริงบนกริด
  2. เก็บศัตรูทุกตัวที่ยืนบนช่องเหล่านั้น (ใช้ `grid_dist`/พิกัดช่อง — docs/11 §3)
  3. คำนวณดาเมจต่อเป้าด้วยสูตรร่วม (docs/01 §4) → emit floating damage พร้อมกัน (docs/11 §8)
- ยังมี safety cap `max_targets` (docs/11 §7) กันเคสฝูงมหาศาลเพื่อ performance/สมดุล
```python
def resolve_shape(caster, skill):
    cells = build_offsets(skill.shape, level=skill.star)   # §3 scaling
    cells = [rotate(o, skill.shape.orientation) for o in cells]
    world = [caster.cell + o for o in cells if in_bounds(caster.cell + o)]
    targets = [e for e in enemies_on(world) if e.alive][:skill.max_targets]
    for t in targets: apply_damage(t, ...)   # docs/01 §4
```

## 2. ทรงพื้นที่ทั้ง 6 แบบ

### แบบ 1 — เส้นตรงมีทิศ (Directional Line)
เส้นตรงพุ่งออกจากตัวละคร **เลือกทิศได้เอง** (หน้า/หลัง/ซ้าย/ขวา) ยาว `length` กว้าง `width`
```
        (length = 3, width = 1, ทิศ = "หน้า")
            . # .
            . # .
            . # .
            . C .
```
- offsets (ทิศหน้า): `(0,1),(0,2),(0,3)`  → หมุนตาม orientation เพื่อยิงหลัง/ซ้าย/ขวา
- `width>1` ขยายข้างเส้น (เช่น width 3 = เพิ่มคอลัมน์ซ้าย-ขวา)
- เหมาะวิชาพุ่งทะลุ/กระบี่ปาด เลือกแนวศัตรูที่เรียงกัน

### แบบ 2 — กากบาทเล็ก 5 ช่อง (Plus-5)
ตัวละคร + 4 ช่องประชิดรอบด้าน รวม 5 ช่อง (ทรงคงที่ ไม่หมุน)
```
            . # .
            # C #
            . # .
```
- offsets: `(0,0),(0,1),(0,-1),(1,0),(-1,0)`
- เหมาะวิชาระยะประชิดเคลียร์รอบตัวแบบเบาๆ ออกถี่

### แบบ 3 — กากบาทเต็มเส้น (Full Cross / Orthogonal Rays)
4 เส้นตรงพุ่งออก 4 ทิศตั้งฉาก จุดตัดที่ตัวละคร ยาวทิศละ `length`
```
            (length = 2)
            . . # . .
            . . # . .
            # # C # #
            . . # . .
            . . # . .
```
- offsets (length L): ทุก `(±i,0),(0,±i)` สำหรับ i=1..L
- เหมาะวิชาแผ่พลังตามแกน โดนศัตรูที่ขนาบ 4 ทิศ

### แบบ 4 — ดาวกระจาย: กากบาท + แนวทแยง (Star Rays)
เหมือนแบบ 3 แต่เพิ่ม **เส้นแนวทแยง** พุ่งออกจากตัวละคร (เส้นรัศมีหลายทิศ)
```
            (length = 2, 8 ทิศ)
            # . # . #
            . # # # .
            # # C # #
            . # # # .
            # . # . #
```
- offsets: orthogonal `(±i,0),(0,±i)` + diagonal `(±i,±i)` สำหรับ i=1..L
- **`directions` ตั้งค่าได้** (data-driven): ค่าเริ่มต้นบนกริดสี่เหลี่ยม = 8 ทิศ (สมมาตรเต็ม)
  > ตามโจทย์ "รวมหกเส้น" สามารถกำหนด `rays` ให้เหลือ 6 ทิศที่ต้องการได้ (เช่น ตัด 2 ทิศทแยง)
  > และถ้าใช้กริด **หกเหลี่ยม (hex)** 6 ทิศคือรูปแบบธรรมชาติของ hex อยู่แล้ว (docs/11 §3)
- เหมาะวิชาระเบิดพลังรอบตัวตามแนวรัศมี

### แบบ 5 — พีระมิด: ตาราง 5×5 + สามเหลี่ยมรอบ (Square + Spikes / Pyramid)
พื้นที่ทึบ 5×5 กลางตัวละคร + สามเหลี่ยมแหลมยื่นออกทั้ง 4 ด้าน (ทรงเพชร/พีระมิดมองบน)
```
            . . . . # . . . .
            . . . # # # . . .
            . . # # # # # . .
            . # # # # # # # .
            # # # # C # # # #
            . # # # # # # # .
            . . # # # # # . .
            . . . # # # . . .
            . . . . # . . . .
```
- core 5×5: `x,y ∈ [-2,2]`
- เงี่ยง (แต่ละด้าน): ระยะ 3 → กว้าง 3 ช่อง, ระยะ 4 → 1 ช่อง (สามเหลี่ยมเรียวออก)
- เหมาะวิชาสุดยอดสายพื้นที่กว้างแต่ยังไม่เต็มวง — ครอบฝูงหนาแน่นกลางสนาม

### แบบ 6 — วงกว้างรอบตัว (Radial / Ultimate)
รัศมีวงกว้างรอบตัวละคร โดน **ทุกช่องในรัศมี R** (ท่าไม้ตายล้างฝูง — ตรงกับ docs/11 §7)
```
            (radius = 3, วัดแบบ Euclidean ให้ดูกลม)
            . . # # # . .
            . # # # # # .
            # # # # # # #
            # # # C # # #
            # # # # # # #
            . # # # # # .
            . . # # # . .
```
- offsets: ทุกช่อง `dist(C, cell) <= R` (เลือก metric ตาม grid mode — Chebyshev = วงสี่เหลี่ยม)
- คือ "สุดยอดวิชา" รัศมีกว้างสุด, max_targets สูงสุด

## 3. การขยายรัศมีตามระดับวิชา (Level / Star Scaling)
"บางวิชารัศมีเปลี่ยนแปลงตามระดับ" — กำหนดใน `shape.scaling` ให้พารามิเตอร์โตตามดาว (★0–10)
```jsonc
"shape": {
  "type": "cross",
  "params": { "length": 2 },
  "orientation": "front",
  "scaling": { "length": "+1 ทุก 3 ดาว", "width": "+1 ที่ ★6 และ ★10" }
}
```
**ตารางตัวอย่างการขยายตามดาว (ต่อ shape):**
| ทรง | พารามิเตอร์โต | ★0 | ★3 | ★6 | ★10 |
|---|---|---|---|---|---|
| 1 เส้นตรง | length / width | 3 / 1 | 4 / 1 | 5 / 3 | 7 / 3 |
| 3 กากบาท | length | 2 | 3 | 4 | 6 |
| 4 ดาวกระจาย | length (8 ทิศ) | 1 | 2 | 3 | 4 |
| 5 พีระมิด | core size / spike | 3×3 +1 | 5×5 +1 | 5×5 +2 | 7×7 +2 |
| 6 วงกว้าง | radius | 2 | 3 | 4 | 5 |
> แบบ 2 (Plus-5) คงที่ตามชื่อ (5 ช่อง) — ใช้เป็นวิชาออกถี่ ราคาถูก ไม่สเกลพื้นที่
> ดาเมจต่อช่องยังสเกลด้วย `skill_mult = base + ★*0.10` (docs/01) แยกจากการขยายพื้นที่

## 4. ทิศทาง & การหมุน (Orientation)
- ทรงมีทิศ (แบบ 1) และทรงไม่สมมาตร เลือก `orientation`:
  - กริดสี่เหลี่ยม: `front / right / back / left` (หมุน 0°/90°/180°/270°)
  - ทรงรวมทแยง (แบบ 4) รองรับหมุน 45° เพิ่มได้
- **วิธีเล็ง (UX มือถือ):** ปัดนิ้วกำหนดทิศก่อนปล่อย / ล็อกทิศไปยังกระจุกศัตรูหนาสุดอัตโนมัติ
- ทรงสมมาตรรอบตัว (2,3,6) ไม่ต้องเล็งทิศ — ปล่อยรอบตัวทันที (เหมาะ auto-script docs/01 §6)
```python
ROT = { "front":0, "right":90, "back":180, "left":270 }
def rotate(off, orientation):
    a = radians(ROT[orientation]); x,y = off
    return ( round(x*cos(a) - y*sin(a)), round(x*sin(a) + y*cos(a)) )
```

## 5. ส่วนขยาย Schema (ต่อจาก docs/10 §1 Skill Schema)
```jsonc
{
  "id": "cloud_cross_strike",
  "name": "กระบี่กากบาทเมฆ",
  "shape": {
    "type": "cross",            // line | plus5 | cross | star | pyramid | radial
    "params": { "length": 2, "width": 1, "radius": 0, "rays": 8 },
    "orientation": "front",     // front|right|back|left (เฉพาะทรงมีทิศ)
    "scaling": { "length": [2,3,4,6] }  // index = ช่วงดาว หรือสูตร string
  },
  "max_targets": 16,            // safety cap (docs/11 §7)
  "falloff": { "inner": 99, "outer_mult": 1.0 }  // ทรงเส้น/กากบาทมักไม่ลดตามระยะ
}
```
**แมประหว่าง type ↔ ตัวสร้าง offset:**
| type | พารามิเตอร์หลัก | สมมาตร/มีทิศ |
|---|---|---|
| `line` | length, width | มีทิศ |
| `plus5` | — (คงที่) | สมมาตร |
| `cross` | length | สมมาตร |
| `star` | length, rays(6/8) | สมมาตร (หมุน 45° ได้) |
| `pyramid` | core, spike | สมมาตร |
| `radial` | radius | สมมาตร |

## 6. การจับคู่ทรงกับสำนัก (ตัวอย่างดีไซน์)
| สำนัก | ทรงเด่น | เหตุผล |
|---|---|---|
| เขาเมฆขาว (กระบี่) | 1 เส้นตรง, 3 กากบาท | ปาดแนว/แทงทะลุ |
| ลมวสันต์ (ตัวเบา) | 1 เส้นตรง, 4 ดาวกระจาย | พุ่งเร็วหลายทิศ |
| กระบองเหล็ก (กาย) | 2 Plus-5, 6 วงกว้าง(ทุบพื้น) | กระแทกรอบตัว |
| หุบเขายาพิษ (พิษ) | 5 พีระมิด, 6 วงกว้าง | แผ่หมอกพิษพื้นที่ |
| วารีบูรพา (ฝ่ามือ) | 3 กากบาท(ฟื้น/บัฟแนว), 6 วงกว้าง(ฟื้นทีม) | utility แนว/รอบตัว |
> ทรงเดียวกันใช้กับวิชาฟื้น/บัฟได้ (เปลี่ยน effect จาก damage → heal/buff, เลือกเป้าเป็นพวกเดียวกัน)

## 7. หมายเหตุการ implement
- เก็บ "ทรง" เป็น **ตาราง offset ที่ pre-compute ต่อ (type, level, orientation)** → เร็ว ไม่คำนวณซ้ำทุก tick
- ตรวจขอบกริด/สิ่งกีดขวาง: ช่องที่ตกนอกสนาม/ติด blocked ตัดออก (หรือให้เส้นถูกบล็อกตามดีไซน์)
- ไฮไลต์ช่องที่จะโดน (telegraph) ก่อนปล่อยท่าหนัก → ทั้งผู้เล่นเล็งและศัตรูหลบ (docs/11 §9)
- ทรง 5,6 ระดับสูง = เป้าจำนวนมาก → ใช้ batched damage events (docs/11 §8) + object pooling floating text
